บทที่ 1

ภาพรวมระบบ

ก่อนลงมือใช้งาน ควรรู้ว่าระบบนี้แก้ปัญหาอะไร ใครใช้ส่วนไหน และคำที่ปรากฏบนหน้าจอแต่ละคำหมายถึงอะไร

1.1ระบบนี้แก้ปัญหาอะไร

คลังสินค้าที่ใช้พาเลทหมุนเวียนระหว่างแผนก มักตอบคำถามพื้นฐานสามข้อไม่ได้

  1. ตอนนี้พาเลทแต่ละใบอยู่ที่ไหน
  2. ใครเป็นคนเบิกออกไป และเบิกไปนานแค่ไหนแล้ว
  3. พาเลทที่ชำรุดมีกี่ใบ ซ่อมไปแล้วกี่ใบ

ระบบจัดการพาเลทแก้ปัญหานี้ด้วยการติด QR Code ไว้ที่พาเลททุกใบ แล้วให้พนักงานสแกนทุกครั้งที่มีการเคลื่อนย้าย ระบบจะบันทึกไว้ว่าใครทำรายการอะไร กับพาเลทใบไหน เมื่อไร และส่งไปที่แผนกใด ผู้ดูแลระบบจึงเห็นสถานะของพาเลททุกใบได้ทันทีจากหน้าจอเดียว พร้อมรายงานสรุปที่ส่งเข้า LINE ให้อัตโนมัติตามเวลาที่ตั้งไว้

1.2ผู้ใช้ 2 บทบาท และอุปกรณ์ที่ใช้

บทบาทอุปกรณ์หน้าที่
พนักงานโทรศัพท์มือถือสแกน QR เพื่อเบิกออก รับคืน และแจ้งพาเลทชำรุด ดูประวัติการทำรายการของตัวเอง
ผู้ดูแลระบบคอมพิวเตอร์ดูภาพรวมทั้งคลัง จัดการข้อมูลพาเลท ผู้ใช้งาน สถานที่ และตั้งค่าระบบ

ระบบเลือกหน้าจอจาก บทบาทที่บันทึกไว้ในบัญชี ไม่ได้เลือกจากขนาดหน้าจอ บัญชีพนักงานที่เปิดบนคอมพิวเตอร์จึงยังเห็นหน้าจอมือถือเหมือนเดิม และบัญชีผู้ดูแลระบบที่เปิดบนมือถือก็ยังเห็นหน้าจอผู้ดูแลระบบ ผู้ใช้ทั้งสองกลุ่มไม่มีหน้าจอไหนใช้ร่วมกันเลย ยกเว้นหน้าเข้าสู่ระบบ

หมายเหตุ

บัญชีหนึ่งมีได้บทบาทเดียวเท่านั้น หากต้องการสลับบทบาทเพื่อทดสอบ ต้องออกจากระบบแล้วเข้าใหม่ด้วยอีกบัญชีหนึ่ง

1.3คำศัพท์ที่ต้องรู้

รหัสพาเลท

รหัสประจำตัวของพาเลทแต่ละใบ เช่น P001 เป็นค่าที่พิมพ์อยู่ใน QR Code และเป็นค่าที่ใช้อ้างอิงพาเลทใบนั้นทั้งระบบ พาเลทสองใบมีรหัสซ้ำกันไม่ได้

สถานะของพาเลท

พาเลททุกใบมีสถานะเดียว ณ เวลาหนึ่ง มีทั้งหมดสี่สถานะ

สถานะความหมาย
พร้อมใช้งานอยู่ในคลัง รอให้เบิก
ถูกเบิกออกถูกเบิกไปอยู่กับแผนกปลายทางแล้ว
ชำรุดถูกแจ้งชำรุดไว้ รอผู้ดูแลระบบตัดสินใจว่าจะซ่อมหรือตัดออกจากระบบ
ตัดออกจากระบบเลิกใช้งานถาวร

ตัดออกจากระบบ เป็นสถานะปลายทาง พาเลทเข้าสถานะนี้ได้จากสถานะชำรุดเท่านั้น และเมื่อเข้าแล้วจะไม่กลับออกมาอีก พาเลทที่ถูกตัดออกจากระบบจะไม่ถูกนับรวมในตัวเลขสรุปทุกตัวบนหน้าภาพรวม และสแกนซ้ำไม่ได้ แต่ประวัติทั้งหมดยังอยู่ครบ

ประเภทรายการ

ทุกครั้งที่สถานะของพาเลทเปลี่ยน ระบบจะบันทึกเป็นหนึ่งรายการ มีห้าประเภท

ประเภทรายการใครทำสถานะหลังทำรายการ
เบิกออกพนักงาน หรือผู้ดูแลระบบถูกเบิกออก
รับคืนพนักงาน หรือผู้ดูแลระบบพร้อมใช้งาน
แจ้งชำรุดพนักงานชำรุด
ซ่อมแล้วผู้ดูแลระบบพร้อมใช้งาน
ตัดออกจากระบบผู้ดูแลระบบตัดออกจากระบบ

สถานที่ / แผนกปลายทาง

รายชื่อปลายทางที่พาเลทถูกเบิกไป เช่น Line A หรือ คลังสินค้า A ผู้ดูแลระบบเป็นผู้เพิ่มและปิดใช้งานรายชื่อนี้ (หัวข้อ 4.5) พนักงานจะเห็นเฉพาะสถานที่ที่ เปิดใช้งาน อยู่เท่านั้นตอนเลือกปลายทาง

เกินกำหนด

พาเลทที่ถูกเบิกออกไปแล้วยังไม่ถูกรับคืนภายในจำนวนวันที่กำหนดไว้ ค่าเริ่มต้นคือ 7 วัน ผู้ดูแลระบบเปลี่ยนค่านี้ได้ที่หน้าตั้งค่า (หัวข้อ 4.6) ระบบใช้ค่านี้ในสามที่: ตัวเลข “เกินกำหนด” บนหน้าภาพรวม ตัวกรอง “เฉพาะเกินกำหนด” ในหน้าคลังพาเลท และรายงานแจ้งเตือนที่ส่งเข้า LINE

“ลบ” ไม่เหมือน “ตัดออกจากระบบ”

สองคำนี้ใกล้กันมากแต่ผลต่างกันสิ้นเชิง จำไว้ให้ขึ้นใจก่อนกดปุ่มในหัวข้อ 4.2

  • ตัดออกจากระบบ — เลิกใช้พาเลทใบนั้น แต่ ประวัติและรูปหลักฐานยังอยู่ครบ ใช้เมื่อพาเลทพังจนซ่อมไม่ได้
  • ลบ — ลบทั้งตัวพาเลทและ ประวัติการทำรายการทั้งหมดของมัน ออกจากฐานข้อมูล กู้คืนไม่ได้ ใช้เฉพาะกรณีสร้างข้อมูลผิดเท่านั้น

1.4วงจรชีวิตของพาเลท

จากสถานะด้วยรายการไปสถานะใครทำ
(เพิ่มเข้าระบบ)สร้างพาเลทพร้อมใช้งานผู้ดูแลระบบ
พร้อมใช้งานเบิกออกถูกเบิกออกพนักงาน
ถูกเบิกออกรับคืนพร้อมใช้งานพนักงาน
พร้อมใช้งาน หรือ ถูกเบิกออกแจ้งชำรุดชำรุดพนักงาน
ชำรุดซ่อมแล้วพร้อมใช้งานผู้ดูแลระบบ
ชำรุดตัดออกจากระบบตัดออกจากระบบ (ปลายทาง)ผู้ดูแลระบบ

อ่านตารางนี้ประกอบสองข้อสำคัญ

  1. ตัดออกจากระบบทำได้จากสถานะชำรุดเท่านั้น สั่งตัดพาเลทที่ยังพร้อมใช้งานหรือกำลังถูกเบิกออกอยู่ไม่ได้ ต้องแจ้งชำรุดก่อน
  2. งานหนึ่งชิ้นข้ามสองบทบาท พนักงานเป็นคนแจ้งชำรุด แต่คนที่กด “ซ่อมแล้ว” หรือ “ตัดออกจากระบบ” คือผู้ดูแลระบบ พาเลทที่ค้างอยู่ในสถานะชำรุดจึงหมายความว่ายังไม่มีใครตัดสินใจ ไม่ได้แปลว่าระบบค้าง
บทที่ 2

เริ่มต้นใช้งาน

หน้าเข้าสู่ระบบเป็นหน้าจอเดียวที่ผู้ใช้ทั้งสองบทบาทเห็นเหมือนกัน หลังเข้าสู่ระบบสำเร็จ ระบบจะพาไปยังหน้าจอตามบทบาทของบัญชีโดยอัตโนมัติ

2.1เข้าสู่ระบบด้วยรหัสพนักงาน

  1. เปิดเว็บไซต์ของระบบ จะพบหน้า “เข้าสู่ระบบ”
  2. กรอก รหัสพนักงาน เช่น EMP001
  3. กรอก รหัสผ่าน
  4. กดปุ่ม “เข้าสู่ระบบ”

เมื่อสำเร็จ พนักงานจะเข้าสู่หน้าหลักบนมือถือ (บทที่ 3) และผู้ดูแลระบบจะเข้าสู่หน้าภาพรวม (บทที่ 4)

หมายเหตุ

ช่องแรกรับอีเมลได้ด้วย แต่ป้ายกำกับเขียนว่า “รหัสพนักงาน” เพราะเป็นสิ่งที่พนักงานทุกคนรู้จัก ระบบจะแปลงรหัสพนักงานเป็นอีเมลสำหรับเข้าสู่ระบบให้เองเมื่อสิ่งที่กรอกไม่มีเครื่องหมาย @

ถ้าเข้าสู่ระบบไม่สำเร็จ

ข้อความที่ขึ้นสาเหตุและวิธีแก้
รหัสพนักงานหรือรหัสผ่านไม่ถูกต้องตรวจว่าพิมพ์รหัสพนักงานถูกต้อง และดูมุมขวาบนของช่องรหัสผ่านว่ามีคำเตือน “Caps Lock เปิดอยู่” หรือไม่
พยายามหลายครั้งเกินไป กรุณารอสักครู่แล้วลองใหม่ระบบจำกัดจำนวนครั้งเพื่อกันการเดารหัสผ่าน รอสักครู่แล้วลองใหม่
ดำเนินการไม่สำเร็จ กรุณาตรวจสอบข้อมูลเข้าสู่ระบบระบบติดต่อฐานข้อมูลไม่ได้ ตรวจการเชื่อมต่ออินเทอร์เน็ต แล้วดูภาคผนวก ก.2

2.2ลืมรหัสผ่าน

  1. ที่หน้าเข้าสู่ระบบ กด “ลืมรหัสผ่าน?” ใต้ช่องรหัสผ่าน
  2. หัวข้อจะเปลี่ยนเป็น “รีเซ็ตรหัสผ่าน” กรอกรหัสพนักงาน
  3. กด “ส่งลิงก์รีเซ็ตรหัสผ่าน”
  4. ระบบขึ้นข้อความว่า หากรหัสนี้ตรงกับบัญชีในระบบ ลิงก์จะถูกส่งไปยังอีเมลของผู้ดูแลระบบที่ลงทะเบียนไว้
  5. กด “กลับไปหน้าเข้าสู่ระบบ” เพื่อกลับไปหน้าเดิม
หมายเหตุ

ลิงก์รีเซ็ตจะถูกส่งไป อีเมลของผู้ดูแลระบบ เสมอ ไม่ใช่อีเมลของพนักงานที่กดขอ เพราะบัญชีพนักงานทั้งหมดใช้อีเมลที่สร้างจากอีเมลหลักของผู้ดูแลระบบ พนักงานทั่วไปจึงควรแจ้งผู้ดูแลระบบให้รีเซ็ตรหัสผ่านให้โดยตรง (วิธีทำอยู่ในหัวข้อ 4.4) ซึ่งเร็วกว่าและไม่ต้องรออีเมล

หมายเหตุ

ระบบขึ้นข้อความเดียวกันเสมอ ไม่ว่ารหัสพนักงานที่กรอกจะมีอยู่จริงหรือไม่ นี่เป็นความตั้งใจ เพราะการบอกว่า “ไม่พบบัญชีนี้” เท่ากับบอกคนนอกว่ารหัสพนักงานไหนมีอยู่ในระบบบ้าง

2.3ตั้งรหัสผ่านใหม่

หน้านี้เปิดจากลิงก์ในอีเมลรีเซ็ตรหัสผ่านเท่านั้น เปิดตรง ๆ ไม่ได้

  1. กดลิงก์ในอีเมล ระบบจะเปิดหน้า “ตั้งรหัสผ่านใหม่”
  2. กรอก รหัสผ่านใหม่ ต้องยาวอย่างน้อย 6 ตัวอักษร
  3. กรอก ยืนยันรหัสผ่าน ให้ตรงกัน ระบบจะขึ้นข้อความ “รหัสผ่านตรงกัน” สีเขียวทันทีที่ตรง
  4. กด “รีเซ็ตรหัสผ่าน”
  5. เมื่อสำเร็จจะขึ้นหัวข้อ “เปลี่ยนรหัสผ่านสำเร็จ” และระบบจะพากลับไปหน้าเข้าสู่ระบบให้เองในอีกสักครู่

ภาษาที่เลือกผูกกับ เครื่อง ไม่ใช่กับบัญชี ออกจากระบบแล้วเข้าใหม่ ภาษาจะยังเป็นภาษาเดิม และการเปลี่ยนภาษาบนเครื่องหนึ่งไม่มีผลกับเครื่องอื่น

2.5ระบบออกจากระบบให้อัตโนมัติเมื่อไร

ข้อความใต้ฟอร์มเข้าสู่ระบบระบุเงื่อนไขไว้ครบแล้ว ระบบจะออกจากระบบให้อัตโนมัติเมื่อ

  1. ปิดเบราว์เซอร์ — เซสชันไม่ถูกเก็บข้ามการปิดเบราว์เซอร์
  2. ไม่มีการใช้งานเกิน 30 นาที — นับจากการแตะหรือคลิกครั้งล่าสุด
  3. ครบ 12 ชั่วโมงนับจากเข้าสู่ระบบ — ต่อให้ใช้งานอยู่ตลอดก็ตาม

เมื่อถูกออกจากระบบ จะขึ้นข้อความ “เซสชันหมดอายุแล้ว กรุณาเข้าสู่ระบบอีกครั้ง” หรือ “ออกจากระบบอัตโนมัติเนื่องจากไม่มีการใช้งาน” แล้วแต่กรณี

ข้อควรระวัง

พนักงานที่กำลังสแกนพาเลทเป็นชุดค้างไว้ แล้วถูกออกจากระบบ รายการที่สแกนไว้แต่ยังไม่กด “ยืนยันและบันทึก” จะหายไปพร้อมเซสชัน รายการที่สแกนค้างไว้เป็นข้อมูลของเซสชันนั้น ๆ และไม่ตกไปถึงคนที่ใช้เครื่องต่อ

บทที่ 3

คู่มือพนักงาน (มือถือ)

บทนี้สำหรับผู้ใช้บทบาทพนักงาน ทุกหน้าจอออกแบบมาสำหรับโทรศัพท์มือถือ งานทั้งหมดของพนักงานมีสี่อย่างเท่านั้น และทำได้จากหน้าหลักทั้งหมด

ข้อควรระวัง

ทุกหน้าจอที่ต้องสแกน ระบบจะขอสิทธิ์เข้าถึงกล้อง ต้องกด “อนุญาต” ครั้งแรกที่ใช้งาน ถ้าเผลอกด “ไม่อนุญาต” ต้องไปเปิดสิทธิ์กล้องให้เว็บไซต์นี้ในตั้งค่าของเบราว์เซอร์เอง

3.1หน้าหลักและ 4 เมนู

แถบบนสุดแสดงชื่อผู้ใช้ ปุ่มสลับภาษา และปุ่มออกจากระบบ ถัดลงมาเป็นเมนูสี่ปุ่ม

ปุ่มคำอธิบายใต้ปุ่มใช้เมื่อหัวข้อ
เบิกออกส่งไปยังแผนกนำพาเลทออกจากคลังไปให้แผนกอื่น3.2
รับคืนคืนเข้าคลังรับพาเลทกลับเข้าคลัง3.3
ประวัติของฉันดูรายการล่าสุดตรวจสอบว่าตัวเองทำรายการอะไรไปบ้าง3.5
แจ้งชำรุดสแกนและแนบรูปหลักฐานเจอพาเลทเสียหาย3.4

3.2เบิกพาเลทออก

งานนี้มีสามขั้น: เลือกปลายทาง → สแกน → ยืนยัน จุดสำคัญคือ สแกนได้หลายใบรวดเดียว แล้วค่อยบันทึกทีเดียวพร้อมกัน ไม่ต้องทำทีละใบ

ขั้นที่ 1 เลือกแผนกปลายทาง

  1. ที่หน้าหลัก กด “เบิกออก”
  2. หน้า “เลือกปลายทาง” จะถามว่า “จะส่งพาเลทไปที่แผนกใด?”
  3. แตะชื่อแผนกที่ต้องการ ระบบจะเปิดกล้องให้ทันที
หมายเหตุ

รายการนี้แสดงเฉพาะสถานที่ที่ผู้ดูแลระบบ เปิดใช้งาน ไว้ ถ้าขึ้นว่า “ไม่มีสถานที่ที่เปิดใช้งาน” ให้ติดต่อผู้ดูแลระบบเปิดใช้งานสถานที่ก่อนตามหัวข้อ 4.5

ขั้นที่ 2 สแกน QR ทีละใบจนครบ

  1. เล็ง QR Code บนพาเลทให้อยู่ในกรอบ ระบบจะสแกนเองโดยไม่ต้องกดถ่าย
  2. เมื่อสแกนติด หน้าจอจะกะพริบสีเขียวพร้อมสั่นสั้น ๆ และแสดงรหัสพาเลทที่เพิ่งเพิ่มเข้ารายการ
  3. สแกนใบถัดไปได้ทันที ทำซ้ำจนครบทุกใบที่จะเบิก

แถบด้านล่างคือ “รายการเบิกออก” แสดงปลายทางที่เลือกไว้ในรูปแบบ ไปยัง: ชื่อแผนก และรายชื่อพาเลทที่สแกนแล้วทั้งหมด ลากขึ้นเพื่อดูรายการเต็ม

  • ลบพาเลทออกจากรายการ — กดปุ่มลบท้ายแถวนั้น (ใช้เมื่อสแกนผิดใบ)
  • ยังไม่ได้สแกนอะไรเลย — แถบจะขึ้นว่า “สแกน QR เพื่อเพิ่มรายการ...”

ขั้นที่ 3 ยืนยันและบันทึก

  1. เมื่อครบแล้ว กด “ยืนยันและบันทึก”
  2. ระบบขึ้นข้อความ “เบิกออกสำเร็จ N พาเลท” แล้วกลับสู่หน้าหลัก พาเลททุกใบในรายการเปลี่ยนสถานะเป็น ถูกเบิกออก และย้ายไปอยู่ที่แผนกปลายทาง
ข้อควรระวัง

รายการที่สแกนไว้จะยัง ไม่ถูกบันทึก จนกว่าจะกด “ยืนยันและบันทึก” ถ้ากดปิดกล้องหรือถูกออกจากระบบก่อน รายการที่ค้างอยู่จะหายไป

3.3รับคืนพาเลทเข้าคลัง

ขั้นตอนเหมือนการเบิกออกทุกอย่าง ยกเว้นไม่ต้องเลือกปลายทาง เพราะปลายทางคือคลังเสมอ

  1. ที่หน้าหลัก กด “รับคืน” ระบบเปิดกล้องทันที
  2. สแกน QR ของพาเลททุกใบที่จะรับคืน
  3. ตรวจรายการใน “รายการรับคืน” ที่แถบด้านล่าง
  4. กด “ยืนยันและบันทึก”
  5. ระบบขึ้น “รับคืนสำเร็จ N พาเลท” พาเลททุกใบกลับเป็นสถานะ พร้อมใช้งาน

3.4แจ้งพาเลทชำรุด

ต่างจากสองงานข้างบนตรงที่ทำได้ ทีละใบ เพราะแต่ละใบต้องแนบรูปหลักฐานของตัวเอง

ขั้นที่ 1 ระบุพาเลทที่ชำรุด

  1. ที่หน้าหลัก กด “แจ้งชำรุด”
  2. สแกน QR ของพาเลทที่เสียหาย ระบบจะพาเข้าฟอร์มให้เองภายในหนึ่งวินาที

ถ้า QR ขาดหรือสแกนไม่ติด แถบด้านล่างมีทางออกให้อยู่แล้ว

  1. กรอก รหัสพาเลท ในช่อง เช่น P001
  2. กด “ยืนยัน”

ขั้นที่ 2 แนบรูปหลักฐานและส่ง

  1. หัวฟอร์มจะขึ้นว่า “แจ้งชำรุด: รหัสพาเลท” ตรวจว่าเป็นใบที่ถูกต้อง
  2. กด “เปิดกล้อง” เพื่อถ่ายรูปความเสียหาย หรือเลือกรูปจากเครื่อง
  3. ระบบจะขึ้น “กำลังบีบอัดรูป...” แล้วแสดงภาพตัวอย่าง กด “ลบรูป” เพื่อถ่ายใหม่ได้
  4. กด “ส่งรายงาน”
  5. ระบบขึ้น “แจ้งชำรุดพาเลท P001 แล้ว” และกลับสู่หน้าหลัก

พาเลทใบนั้นเปลี่ยนเป็นสถานะ ชำรุด ทันที และจะสแกนเบิกออกหรือรับคืนไม่ได้อีก จนกว่าผู้ดูแลระบบจะกด “ซ่อมแล้ว” หรือ “ตัดออกจากระบบ” (หัวข้อ 4.2)

หมายเหตุ

รูปหลักฐานถูกเก็บไว้กับรายการนั้น ผู้ดูแลระบบเปิดดูได้จากหน้าประวัติรายการ (หัวข้อ 4.3) รูปจะถูกลบเมื่อพาเลทถูกกดว่าซ่อมแล้ว

3.5ดูประวัติของฉัน

หน้านี้แสดงเฉพาะรายการที่ ตัวเองเป็นคนทำ ไม่เห็นของคนอื่น

จากหน้าหลัก กด “ประวัติของฉัน” จะพบเครื่องมือคัดกรองสี่ชิ้นเรียงจากบนลงล่าง

เครื่องมือใช้ทำอะไร
ช่องค้นหาค้นด้วยรหัสพาเลทหรือชื่อสถานที่
เมนูสถานที่เลือกดูเฉพาะสถานที่เดียว หรือ “ทุกสถานที่”
เมนูวันที่เลือก “ล่าสุด (50 รายการ)” หรือเจาะจงวันที่ ปุ่มวันที่เขียนแบบ 29-Jul
แถบประเภทรายการทั้งหมด / เบิกออก / รับคืน / ชำรุด

แต่ละแถวแสดงรหัสพาเลท ประเภทรายการ เวลา และปลายทาง (ขึ้นต้นด้วย ไปยัง:) ท้ายรายการบอกจำนวนที่แสดงอยู่ในรูปแบบ แสดง N รายการ

ถ้ากรองจนไม่เหลืออะไร ระบบจะขึ้น “ไม่พบรายการ” พร้อมคำแนะนำให้ลองเปลี่ยนวันที่ และปุ่ม “ล้างตัวกรอง” ให้กดกลับมาดูทั้งหมดได้ในคลิกเดียว

3.6ข้อความที่ขึ้นตอนสแกน แปลว่าอะไร

เมื่อสแกนไม่ผ่าน หน้าจอจะกะพริบสีแดงพร้อมข้อความ ต้องแตะหน้าจอเพื่อปิดข้อความก่อน จึงจะสแกนใบถัดไปได้ ตารางนี้ครอบคลุมทุกข้อความที่ระบบขึ้นได้

ข้อความเกิดตอนไหนต้องทำอย่างไร
อยู่ในรายการแล้วสแกนพาเลทใบเดิมซ้ำในรอบเดียวกันไม่ต้องทำอะไร ใบนั้นอยู่ในรายการแล้ว สแกนใบถัดไปได้เลย
ไม่พบพาเลทนี้รหัสใน QR ไม่มีอยู่ในระบบแจ้งผู้ดูแลระบบให้เพิ่มพาเลทใบนี้เข้าระบบก่อน (หัวข้อ 4.2)
พาเลทชำรุดสแกนพาเลทที่อยู่ในสถานะชำรุด เพื่อเบิกออกหรือรับคืนพาเลทใบนี้รอผู้ดูแลระบบจัดการอยู่ ยังใช้งานไม่ได้
พาเลทถูกตัดออกแล้วสแกนพาเลทที่ถูกตัดออกจากระบบ เพื่อเบิกออกหรือรับคืนพาเลทใบนี้เลิกใช้งานถาวรแล้ว ต้องคัดออกจากกอง
แจ้งชำรุดไปแล้วสแกนเพื่อแจ้งชำรุด แต่ใบนั้นถูกแจ้งไปก่อนแล้วไม่ต้องแจ้งซ้ำ
ตัดออกไปแล้วสแกนเพื่อแจ้งชำรุด แต่ใบนั้นถูกตัดออกจากระบบแล้วไม่ต้องแจ้ง พาเลทใบนี้ไม่อยู่ในระบบแล้ว
สแกนไม่สำเร็จระบบติดต่อฐานข้อมูลไม่ได้ตรวจสัญญาณอินเทอร์เน็ต แล้วลองใหม่
ไม่สามารถเข้าถึงกล้องได้ หรือเปิดเครื่องสแกนไม่สำเร็จเบราว์เซอร์ไม่ได้รับสิทธิ์ใช้กล้องเปิดสิทธิ์กล้องให้เว็บไซต์นี้ในตั้งค่าเบราว์เซอร์ (ดูภาคผนวก ก.6)
บันทึกรายการไม่สำเร็จ กรุณาลองใหม่อีกครั้งกด “ยืนยันและบันทึก” แล้วบันทึกไม่ผ่านรายการที่สแกนไว้ยังอยู่ ตรวจสัญญาณแล้วกดยืนยันซ้ำได้
บทที่ 4

คู่มือผู้ดูแลระบบ

บทนี้สำหรับผู้ใช้บทบาทผู้ดูแลระบบ ออกแบบมาสำหรับหน้าจอคอมพิวเตอร์ เมนูด้านซ้ายมีหกรายการ เรียงตามลำดับหัวข้อในบทนี้พอดี

เมนูหัวข้อใช้ทำอะไร
ภาพรวม4.1ดูตัวเลขสรุปและกราฟวิเคราะห์ทั้งคลัง
คลังพาเลท4.2จัดการข้อมูลพาเลททุกใบ
ประวัติรายการ4.3ดูและแก้ไขประวัติการทำรายการทั้งหมด
ผู้ใช้งาน4.4สร้างบัญชี เปลี่ยนบทบาท รีเซ็ตรหัสผ่าน

บนหน้าจอแคบ เมนูด้านซ้ายจะยุบเป็นปุ่มขีดสามขีดที่มุมบนซ้าย

4.1ภาพรวม

หน้าแรกที่เห็นหลังเข้าสู่ระบบ หัวข้อหน้าคือ “ภาพรวมระบบ” คำโปรยว่า “วิเคราะห์การใช้งานและเฝ้าระวังความเสี่ยง”

ปุ่มบนหัวข้อหน้า

ปุ่มผลลัพธ์
พิมพ์รายงานเมนูสองตัวเลือก: พิมพ์ (แนวนอน) และ พิมพ์ (แนวตั้ง)
ส่งออกข้อมูลเมนูสามตัวเลือก: ส่งออกสรุปภาพรวม, ส่งออกคลังพาเลท (CSV), ส่งออกประวัติรายการ (CSV)
หมายเหตุ

ถ้ากดพิมพ์แล้วไม่มีอะไรเกิดขึ้น ให้ดูว่าเบราว์เซอร์บล็อกป๊อปอัปอยู่หรือไม่ ระบบจะขึ้นข้อความเตือนไว้ให้แล้ว

เลือกแนวกระดาษ

ปุ่ม พิมพ์รายงาน มีให้เลือกสองแนว และมีอยู่เหมือนกันทั้งสามหน้า (ภาพรวม คลังพาเลท ประวัติรายการ)

ตัวเลือกเหมาะกับ
พิมพ์ (แนวนอน)หน้าภาพรวม และตารางที่มีหลายคอลัมน์ — เป็นค่าเริ่มต้น
พิมพ์ (แนวตั้ง)รายงานที่มีคอลัมน์ไม่มาก และต้องการให้ได้จำนวนแถวต่อแผ่นมากขึ้น

  • การ์ดไม่ถูกตัดกลางหน้า กราฟหรือกล่องตัวเลขที่ตกขอบล่างจะถูกยกไปทั้งใบยังหน้าถัดไป
  • หัวตารางซ้ำทุกหน้า ตารางที่ยาวข้ามหน้า หน้าที่ 2 เป็นต้นไปยังมีชื่อคอลัมน์กำกับ
  • แถวไม่ถูกตัดครึ่ง ไม่มีแถวไหนที่ครึ่งบนอยู่หน้าหนึ่งครึ่งล่างอยู่อีกหน้า
  • กราฟกว้างพอดีกระดาษ ความกว้างถูกปรับตามแนวที่เลือก ไม่ล้นขอบขวา
  • ตัวควบคุมไม่ติดไปด้วย ปุ่ม แถบตัวกรอง ช่องติ๊กเลือก และแถบเลขหน้า ไม่ปรากฏบนกระดาษ
  • หัวรายงานบนกระดาษ ทุกแผ่นแรกมีชื่อรายงาน วันเวลาที่ออก และบรรทัดบอกตัวกรองที่ใช้อยู่

4.2คลังพาเลท

หน้านี้คือทะเบียนพาเลททุกใบในระบบ หัวข้อหน้าคือ “จัดการคลังพาเลท”

ปุ่มบนหัวข้อหน้า

ปุ่มผลลัพธ์
พิมพ์รายงานเมนูสองตัวเลือก: พิมพ์ (แนวนอน) และ พิมพ์ (แนวตั้ง) ดูรายละเอียดที่ “เลือกแนวกระดาษ” ในหัวข้อ 4.1
ส่งออกข้อมูลดาวน์โหลดไฟล์ CSV เฉพาะแถวที่ผ่านตัวกรองอยู่ตอนนี้

หมายเหตุ

ทั้งไฟล์ CSV และกระดาษที่พิมพ์ ยึดตามตัวกรองที่ตั้งไว้ตอนนั้น ไม่ใช่แค่หน้าที่กำลังเปิดอยู่ — กรองเหลือ 137 แถวแล้วอยู่ที่หน้า 1 (ซึ่งแสดง 20 แถว) กดพิมพ์จะได้ครบทั้ง 137 แถว ถ้าต้องการทั้งคลัง ให้กด “ล้างตัวกรอง” ก่อน

บนกระดาษจะมี คอลัมน์รูปหลักฐานเพิ่มเข้ามาอีกหนึ่งคอลัมน์ ซึ่งไม่มีบนหน้าจอ โดยจะแสดงรูปแจ้งชำรุดล่าสุดของพาเลทใบนั้น (ใบที่ไม่เคยมีรายงานชำรุดจะเว้นว่าง) ต้องต่ออินเทอร์เน็ตอยู่ตอนสั่งพิมพ์ เพราะเบราว์เซอร์โหลดรูปมาวางบนกระดาษให้ตอนนั้น และต้องสั่งพิมพ์ผ่านปุ่มนี้ ไม่ใช่ Ctrl+P (Ctrl+P จะได้ทุกอย่างยกเว้นรูป)

แถบสถานะและตัวกรอง

แถบสถานะด้านบนตารางเป็นปุ่มกรองแบบกดครั้งเดียว: ทั้งหมดที่ยังใช้งาน / พร้อมใช้งาน / ถูกเบิกออก / ชำรุด / เกินกำหนด แต่ละปุ่มแสดงจำนวนกำกับไว้ ส่วนพาเลทที่ถูกตัดออกจากระบบไม่อยู่ในแถบนี้ แต่มีบรรทัดแยกอยู่ใต้แถบว่า ตัดออกจากระบบแล้ว N รายการ พร้อมปุ่ม “ดูรายการ”

เพิ่มพาเลทใหม่

  1. กด “เพิ่มพาเลท”
  2. ช่อง รหัสพาเลท ระบบเติมเลขถัดไปให้อัตโนมัติ (เช่น มีถึง P023 อยู่แล้ว จะเติม P024 ให้) ระหว่างที่กำลังคำนวณ ช่องนี้จะกดไม่ได้ชั่วครู่ ช่องอื่นยังกรอกได้ตามปกติ — แก้เป็นรหัสอื่นได้เสมอ ระบบแค่เติมค่าตั้งต้นให้ ไม่ได้ล็อกไว้
  3. ช่อง จำนวน ใส่ได้ 1–100 ใบ ใต้ช่องจะขึ้นบรรทัดบอกช่วงที่จะได้ เช่น จะสร้าง P024 – P043 รวม 20 ใบ บรรทัดนี้เปลี่ยนตามที่พิมพ์ทันที ตรวจรหัสสุดท้ายในบรรทัดนี้ก่อนกดยืนยันเสมอ เพราะเป็นเลขที่ต้องเอาไปเทียบกับสติกเกอร์ QR ที่กำลังจะพิมพ์
  4. เลือก สถานที่เริ่มต้น
  5. กด “สร้างพาเลท”
  6. ระบบขึ้น “สร้างพาเลท 20 ใบ P024 – P043 เรียบร้อยแล้ว” (ถ้าสร้างใบเดียวจะขึ้น “สร้างพาเลท P024 เรียบร้อยแล้ว”) พาเลททุกใบมีสถานะ พร้อมใช้งาน

ทำไมไม่นำรหัสที่ลบไปแล้วกลับมาใช้ซ้ำ เพราะรหัสอยู่บนสติกเกอร์ QR ที่แปะบนพาเลทจริง ถ้าเอาเลขเก่ากลับมาใช้ ประวัติของพาเลทใบเก่ากับใบใหม่จะปนกันอยู่ใต้รหัสเดียวกันในทุกรายงาน และแยกย้อนหลังไม่ได้อีกเลย

ถ้าพิมพ์รหัสที่ไม่มีตัวเลขท้าย เช่น TEST หรือ SPECIAL-01 ช่องจำนวนจะถูกล็อกเป็น 1 พร้อมข้อความบอกว่า รหัสนี้ไม่มีตัวเลขท้ายรหัส จึงไม่มีลำดับให้นับต่อ เพิ่มได้ครั้งละ 1 ใบเท่านั้น — สร้างได้ปกติ แต่ทีละใบ

ถ้ารหัสซ้ำ (เช่น แอดมินอีกคนเพิ่งสร้างรหัสนั้นไปในอีกแท็บหนึ่ง) ระบบจะ ไม่สร้างสักใบเลยทั้งชุด แล้วขึ้นข้อความใต้ช่องรหัสว่ารหัสไหนที่ชน พร้อมปุ่ม “คำนวณเลขใหม่” กดแล้วระบบดึงรายการล่าสุดมาคำนวณเลขที่ว่างให้ใหม่ ไม่ต้องปิดเปิดกล่องใหม่ — ค่าที่กรอกไว้ในช่องอื่นยังอยู่ครบ

หลังสร้างเสร็จ ให้พิมพ์ QR Code ของพาเลทใบนั้นไปติดที่ตัวพาเลทจริง

การกระทำกับพาเลททีละใบ

คลิกที่แถวใดก็ได้เพื่อเปิดหน้าต่าง รายละเอียดพาเลท ซึ่งแสดงสถานที่ปัจจุบัน รายการล่าสุด และไทม์ไลน์ประวัติทั้งหมดของพาเลทใบนั้น พร้อมชื่อผู้ทำรายการและรูปหลักฐาน

ลบ กับ ตัดออกจากระบบ ไม่เหมือนกัน การลบทำให้ประวัติการทำรายการทั้งหมดของพาเลทใบนั้นหายไปด้วยและกู้คืนไม่ได้ ถ้าต้องการเลิกใช้พาเลทแต่ยังเก็บประวัติไว้ ให้เลือก ตัดออกจากระบบ เสมอ ระบบเขียนคำเตือนนี้ไว้ในหน้าต่างยืนยันแล้ว ให้อ่านก่อนกด

ข้อควรระวัง

การแก้ไข รหัสพาเลท จะไปอัปเดตการอ้างอิงในประวัติทั้งหมดด้วย ระบบขึ้นคำเตือนไว้ในฟอร์มแก้ไขแล้ว

ทำรายการกับพาเลทหลายใบพร้อมกัน

  1. ติ๊กช่องหน้าแถวที่ต้องการ หรือติ๊กช่องบนหัวตารางเพื่อเลือกทั้งหน้า
  2. แถบเครื่องมือจะโผล่ขึ้นมาพร้อมข้อความ เลือกไว้ N รายการ และปุ่มเหล่านี้

ทำรายการเปิดหน้าต่างสร้างรายการเบิกออกหรือรับคืนให้ทุกใบที่เลือก

  1. เลือก ประเภทรายการ: เบิกออก หรือ รับคืน
  2. ถ้าเลือกเบิกออก ต้องเลือก ปลายทาง ด้วย
  3. แก้ วันที่ และ เวลา ได้ ใช้เมื่อบันทึกย้อนหลังให้รายการที่เกิดไปแล้ว
  4. ใส่ หมายเหตุเพิ่มเติม (ถ้ามี)
  5. กด “ยืนยัน” ระบบขึ้น ทำรายการสำเร็จ N รายการ

ถ้าบางใบทำไม่สำเร็จ ระบบจะบอกทั้งจำนวนที่สำเร็จและรหัสที่ไม่สำเร็จ ไม่ใช่ล้มทั้งชุดเงียบ ๆ

พิมพ์ QR Code

หน้าต่าง “แผ่นรวม QR พาเลท” บอกจำนวนที่เลือกไว้ และมีสองปุ่ม

  • พิมพ์ / PDF — เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ เลือก “บันทึกเป็น PDF” ได้จากตรงนั้น
  • ดาวน์โหลด PNG — บันทึกแผ่น QR เป็นไฟล์รูป

QR แต่ละใบมีรหัสพาเลทกำกับใต้ภาพ พร้อมข้อความ ทรัพย์สินของ NMT แสดงความเป็นเจ้าของ

4.3ประวัติรายการ

หน้านี้เก็บทุกรายการที่เคยเกิดในระบบ ไม่ว่าใครทำ หัวข้อหน้าคือ “จัดการประวัติรายการ”

ตัวกรองใช้ทำอะไร
ช่องค้นหาค้นด้วยรหัสพาเลท หรือข้อความในหมายเหตุ
กรองตามผู้ใช้เลือกดูเฉพาะรายการของคนใดคนหนึ่ง
กรองตามสถานที่เลือกสถานที่เดียว
กรองตามประเภทรายการเบิกออก / รับคืน / แจ้งชำรุด / ซ่อมแล้ว / ตัดออกจากระบบ
วันที่เริ่ม / ถึงวันที่กรองตามช่วงเวลา

ตารางมีคอลัมน์ วันที่และเวลา / รหัสพาเลท / ประเภทรายการ / ผู้ทำรายการ / สถานที่ / หมายเหตุ / หลักฐาน แถวที่มีรูปหลักฐานจะมีปุ่ม “ดูรูปหลักฐาน” กดเพื่อเปิดรูปเต็ม ปุ่มท้ายแถวมี “แก้ไขรายการ” และ “ลบรายการนี้”

แก้ไขรายการย้อนหลัง

  1. กดปุ่มแก้ไขท้ายแถวที่ต้องการ
  2. วันที่ (แก้ไขไม่ได้) — ช่องนี้แสดงไว้ให้ดูเฉย ๆ แก้ไม่ได้
  3. แก้ สถานที่/ปลายทาง และ หมายเหตุ ได้
  4. กด “บันทึกการแก้ไข”
หมายเหตุ

ระบบจะต่อท้ายหมายเหตุด้วยข้อความ (แก้ไข: วันที่, เวลา โดย ชื่อผู้แก้) โดยอัตโนมัติ เพื่อให้รู้ว่ารายการนี้ถูกแก้ภายหลัง

ข้อควรระวัง

การแก้ไข รายการล่าสุด ของพาเลทใบหนึ่ง จะทำให้ระบบอัปเดตสถานที่ปัจจุบันของพาเลทใบนั้นตามไปด้วย ระบบเขียนหมายเหตุนี้ไว้ในหน้าต่างแก้ไขแล้ว

พิมพ์ ส่งออก และล้างข้อมูลเก่า

  • พิมพ์รายงาน — เมนูสองตัวเลือก พิมพ์ (แนวนอน) / พิมพ์ (แนวตั้ง) เหมือนหน้าภาพรวมและหน้าคลังพาเลท ได้ทุกแถวที่ผ่านตัวกรอง ไม่ใช่แค่หน้าที่เปิดอยู่
  • ส่งออกข้อมูล — ดาวน์โหลดรายการตามตัวกรองที่ตั้งไว้ ระบบบอกจำนวนที่ส่งออกเมื่อเสร็จ
  • ล้างข้อมูลเก่า — ลบรายการที่เก่ากว่า 2 ปีออกจากฐานข้อมูล
คำเตือน

การล้างข้อมูลเก่าลบข้อมูลอย่างถาวรและย้อนกลับไม่ได้ ควรกด ส่งออกข้อมูล เก็บไว้ก่อนทุกครั้ง

4.4ผู้ใช้งาน

หัวข้อหน้าคือ “จัดการผู้ใช้งาน” ใช้จัดการบัญชีทั้งพนักงานและผู้ดูแลระบบ

ตารางมีคอลัมน์ รหัสพนักงาน / ชื่อ-นามสกุล / สถานที่ / บทบาท / วันที่สร้าง / เข้าใช้งานล่าสุด กรองได้ด้วยช่องค้นหา (ชื่อหรือรหัสพนักงาน) ตัวกรองสถานที่ และตัวกรองบทบาท คลิกที่หัวคอลัมน์เพื่อเรียงลำดับได้

เพิ่มผู้ใช้งานใหม่

  1. กด “เพิ่มผู้ใช้งาน”
  2. กรอก รหัสพนักงาน — ต้องไม่ซ้ำ เพราะระบบใช้ค่านี้สร้างอีเมลสำหรับเข้าสู่ระบบ
  3. กรอก ชื่อ-นามสกุล
  4. เลือก แผนก
  5. เลือก บทบาท: พนักงาน หรือ ผู้ดูแลระบบ
  6. กรอก รหัสผ่าน และ ยืนยันรหัสผ่าน ให้ตรงกัน
  7. กด “สร้างผู้ใช้งาน”
หมายเหตุ

ถ้าสร้างบัญชีผู้ดูแลระบบแล้วขึ้นข้อความว่าสร้างสำเร็จแต่ยังเป็นสิทธิ์พนักงานอยู่ แปลว่า บัญชีถูกสร้างแล้วจริง เพียงแต่ให้สิทธิ์ผู้ดูแลระบบไม่สำเร็จ อย่ากดสร้างซ้ำ ให้ไปเปลี่ยนบทบาทจากตารางแทน

แก้ไข เปลี่ยนบทบาท และรีเซ็ตรหัสผ่าน

ปุ่มผลลัพธ์
แก้ไขผู้ใช้งานเปลี่ยนแถวนั้นเป็นช่องกรอก แก้ แผนก และ บทบาท ได้ในแถวเลย แล้วกด บันทึก
รีเซ็ตรหัสผ่านเปิดหน้าต่างตั้งรหัสผ่านใหม่ให้ผู้ใช้คนนั้นโดยตรง
ลบผู้ใช้งานลบบัญชีถาวร

วิธีรีเซ็ตรหัสผ่านให้พนักงานที่ลืมรหัส — นี่คือวิธีที่เร็วที่สุด และเป็นวิธีที่ควรใช้แทนการให้พนักงานกด “ลืมรหัสผ่าน?” เอง (ดูเหตุผลในหัวข้อ 2.2)

  1. ค้นหาชื่อหรือรหัสพนักงานคนนั้น
  2. กดปุ่ม “รีเซ็ตรหัสผ่าน” ท้ายแถว
  3. หน้าต่างจะขึ้นว่า กำลังรีเซ็ตรหัสผ่านของ ชื่อพนักงาน — ตรวจว่าเป็นคนที่ถูกต้อง
  4. กรอก รหัสผ่านใหม่ และ ยืนยันรหัสผ่านใหม่
  5. กด “ยืนยันการรีเซ็ต” แล้วแจ้งรหัสใหม่ให้พนักงานคนนั้นทราบ
คำเตือน

การลบผู้ใช้งานย้อนกลับไม่ได้ ระบบจะถามยืนยันพร้อมระบุชื่อและรหัสพนักงาน ให้อ่านชื่อในหน้าต่างยืนยันก่อนกดทุกครั้ง

4.5สถานที่

หัวข้อหน้าคือ “จัดการสถานที่” รายการในหน้านี้คือสิ่งที่พนักงานเห็นตอนเลือกปลายทางในหัวข้อ 3.2

ตารางมีคอลัมน์ ลำดับ / ชื่อสถานที่ / รวม / เกินกำหนด / ชำรุด / อัปเดตล่าสุด / สถานะ / จัดการ ตัวเลขในคอลัมน์กลางบอกว่าสถานที่นั้นมีพาเลทอยู่กี่ใบ และมีปัญหากี่ใบ

ตัวกรองมีสองชุด: ทุกสถานะ (เปิด/ปิดใช้งาน) และ ทุกเงื่อนไข ซึ่งเลือกได้เป็น มีพาเลท / ไม่มีพาเลท / ⚠ มีพาเลทเกินกำหนด / ⚠ มีพาเลทชำรุด

เพิ่มสถานที่

  1. กด “เพิ่มสถานที่”
  2. กรอกชื่อ เช่น คลังสินค้า A
  3. กด “บันทึกสถานที่”
หมายเหตุ

ชื่อสถานที่ห้ามซ้ำ และระบบเทียบชื่อโดย ไม่สนตัวพิมพ์ใหญ่-เล็กและช่องว่างหน้าหลัง ดังนั้น Line A กับ line a ถือเป็นสถานที่เดียวกัน

เปิด/ปิดใช้งาน และลบ

ปุ่มผลลัพธ์
แก้ไขชื่อเปลี่ยนแถวเป็นช่องกรอก แก้ชื่อแล้วกด บันทึกการแก้ไข
ปิดใช้งานสถานที่ยังอยู่ในระบบ แต่พนักงานจะไม่เห็นในหน้าเลือกปลายทางอีก
เปิดใช้งานกลับมาให้พนักงานเลือกได้
ลบสถานที่ลบถาวร
หมายเหตุ

ลบสถานที่ที่ยังถูกใช้งานอยู่ไม่ได้ ระบบจะขึ้นว่า ลบไม่ได้ เนื่องจากสถานที่นี้ถูกใช้งานอยู่ กรุณาปิดใช้งานแทน — ในกรณีนี้ให้ใช้ ปิดใช้งาน ซึ่งได้ผลเหมือนกันโดยไม่ทำให้ประวัติเสียหาย

4.6ตั้งค่า

หัวข้อหน้าคือ “ตั้งค่าระบบ” แบ่งเป็นสามส่วนเรียงจากบนลงล่าง

ส่วนที่ 1 การแจ้งเตือนและรายงานอัตโนมัติ

ช่องความหมาย
เกณฑ์เกินกำหนดจำนวนวัน พาเลทที่ถูกเบิกออกนานเกินค่านี้จะถูกนับว่าเกินกำหนด ค่าเริ่มต้น 7 วัน
วันส่งรายงานอัตโนมัติปุ่มวันในสัปดาห์ จ. อ. พ. พฤ. ศ. ส. อา. กดเลือกได้หลายวัน
เวลาส่งแจ้งเตือนเวลาส่งรายงานพาเลทเกินกำหนดในรอบเช้า
เวลาส่งสรุปประจำวันเวลาส่งรายงานสรุปในรอบเย็น

เมนู “ทดสอบ” มีสองคำสั่งสำหรับส่งทันทีโดยไม่ต้องรอเวลาจริง: ส่งแจ้งเตือน และ ส่งสรุป หน้าตาของรายงานที่ส่งออกไปจริง และเงื่อนไขว่าระบบจะส่งเมื่อไร อยู่ในหัวข้อ 4.7

ข้อควรระวัง

  2. ช่อง Email ให้ใส่อีเมลในรูปแบบ ชื่อผู้ใช้+รหัสพนักงาน@โดเมน เช่น อีเมลหลักคือ your-email@gmail.com และรหัสพนักงานคือ ADMIN01 ต้องใส่ว่า your-email+ADMIN01@gmail.com
  3. ตั้งรหัสผ่าน
  4. ใส่ User Metadata เป็น JSON ดังนี้
{
  "employee_id": "ADMIN01",
  "full_name": "ชื่อ นามสกุล",
  "department": "Warehouse"
}

ขั้นที่ 2 ยกระดับเป็นผู้ดูแลระบบ

ไปที่ SQL Editor แล้วรันคำสั่งนี้ โดยเปลี่ยน ADMIN01 เป็นรหัสพนักงานที่ใช้จริง

update public.users set role = 'admin' where employee_id = 'ADMIN01';

ขั้นที่ 3 ทดสอบ

เข้าสู่ระบบด้วยรหัสพนักงาน ADMIN01 และรหัสผ่านที่ตั้งไว้ ต้องเข้าสู่หน้าภาพรวมของผู้ดูแลระบบ ไม่ใช่หน้าจอมือถือของพนักงาน หลังจากนี้บัญชีอื่นทั้งหมดสร้างจากหน้าผู้ใช้งานได้ตามหัวข้อ 4.4 ไม่ต้องกลับมาทำขั้นนี้อีก

หมายเหตุ

ระบบกันไม่ให้ลบผู้ดูแลระบบคนสุดท้ายออกจากระบบ จึงไม่มีทางเผลอทำให้ฐานข้อมูลไม่เหลือผู้ดูแลระบบเลย

ก.5ตั้งค่า LINE Messaging API

ข้ามหัวข้อนี้ได้ถ้ายังไม่ต้องการให้ระบบส่งรายงานเข้า LINE ส่วนอื่นทั้งหมดใช้งานได้ตามปกติ

ขั้นที่ 1 หาค่าจาก LINE Developers Console

  1. เข้า developers.line.biz แล้วสร้าง Provider และ Channel แบบ Messaging API
  2. ที่แท็บ Messaging API คัดลอก Channel access token (ถ้ายังไม่มี ให้กดออกใหม่)
  3. ที่แท็บ Basic settings คัดลอก Your user ID
  4. เพิ่มบัญชี LINE Official Account ของ Channel นี้เป็นเพื่อนในแอป LINE ของผู้รับรายงาน

ขั้นที่ 2 กรอกลงในระบบ

  1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ ไปที่เมนู ตั้งค่า
  2. วางค่าลงในช่อง Channel Access Token และ Your user ID
  3. กด “บันทึกการเปลี่ยนแปลง” ป้ายสถานะต้องเปลี่ยนเป็น “ตั้งค่าแล้ว”
  4. กดเมนู “ทดสอบ” แล้วเลือก “ส่งแจ้งเตือน” เพื่อตรวจว่าข้อความเข้า LINE จริง

ขั้นที่ 3 เปิดรายงานอัตโนมัติ

การส่งทดสอบในขั้นที่ 2 ใช้งานได้ทันทีโดยไม่ต้องทำขั้นนี้ แต่การส่งอัตโนมัติตามเวลาต้องมีสองอย่างเพิ่ม

  1. ติดตั้ง Edge Function ชื่อ scheduled-report ในโฟลเดอร์ supabase/functions/scheduled-report/ ขึ้นโปรเจค Supabase
  2. ตั้งค่าลับชื่อ REPORT_TRIGGER_SECRET ให้ฟังก์ชันนั้น แล้วตั้งงานตามเวลา (cron) ให้เรียกฟังก์ชันพร้อมส่งค่าลับนี้ในส่วนหัวของคำขอ
หมายเหตุ

ค่าลับนี้เป็นสิ่งที่พิสูจน์ว่าผู้เรียกคืองานตามเวลาจริง ไม่ใช่คนนอกที่เดาที่อยู่ของฟังก์ชันได้ ถ้าไม่ตั้งค่านี้ รายงานอัตโนมัติจะไม่ทำงาน แต่ปุ่มทดสอบส่งในหน้าตั้งค่ายังใช้ได้ตามปกติ เพราะพิสูจน์ตัวตนด้วยบัญชีผู้ดูแลระบบที่กำลังเข้าสู่ระบบอยู่

ก.6รันระบบ และข้อควรรู้เรื่องกล้องกับ HTTPS

รันสำหรับพัฒนา

npm run dev

เปิดเบราว์เซอร์ที่ https://localhost:3000

หมายเหตุ

เป็น https ไม่ใช่ http และเป็นพอร์ต 3000 โปรเจคนี้เปิด HTTPS ไว้ที่เครื่องพัฒนาโดยตั้งใจ เพราะกล้องของมือถือใช้งานไม่ได้เลยถ้าไม่ใช่การเชื่อมต่อที่ปลอดภัย ใบรับรองที่ใช้เป็นแบบสร้างเอง เบราว์เซอร์จะเตือนว่าไม่ปลอดภัยในครั้งแรก ให้กดยืนยันเข้าใช้งานต่อได้

ทดสอบบนมือถือจริง

  1. ดูเลข IP ของเครื่องที่รันเซิร์ฟเวอร์ เช่น 192.168.1.20
  2. บนมือถือที่ต่อ Wi-Fi วงเดียวกัน เปิด https://192.168.1.20:3000
  3. กดยอมรับคำเตือนเรื่องใบรับรอง
  4. เข้าสู่ระบบด้วยบัญชีพนักงาน แล้วกด “เบิกออก” เพื่อทดสอบว่ากล้องเปิดได้
ข้อควรระวัง

ถ้าเปิดด้วย http:// ธรรมดา กล้องจะไม่ทำงาน และหน้าจอจะขึ้นว่า “ไม่สามารถเข้าถึงกล้องได้ หรือเปิดเครื่องสแกนไม่สำเร็จ” ซึ่งดูเหมือนระบบพัง ทั้งที่สาเหตุคือโปรโตคอล ตรวจว่าที่อยู่ขึ้นต้นด้วย https:// เสมอ
