# บทที่ 4 คู่มือผู้ดูแลระบบ

บทนี้สำหรับผู้ใช้บทบาท **ผู้ดูแลระบบ** ออกแบบมาสำหรับหน้าจอคอมพิวเตอร์
เมนูด้านซ้ายมีหกรายการ เรียงตามลำดับหัวข้อในบทนี้พอดี

| เมนู | หัวข้อ | ใช้ทำอะไร |
|---|---|---|
| **ภาพรวม** | 4.1 | ดูตัวเลขสรุปและกราฟวิเคราะห์ทั้งคลัง |
| **คลังพาเลท** | 4.2 | จัดการข้อมูลพาเลททุกใบ |
| **ประวัติรายการ** | 4.3 | ดูและแก้ไขประวัติการทำรายการทั้งหมด |
| **ผู้ใช้งาน** | 4.4 | สร้างบัญชี เปลี่ยนบทบาท รีเซ็ตรหัสผ่าน |
| **สถานที่** | 4.5 | จัดการรายชื่อแผนกปลายทาง |
| **ตั้งค่า** | 4.6 | เกณฑ์เกินกำหนด รายงานอัตโนมัติ และ LINE |

บนหน้าจอแคบ เมนูด้านซ้ายจะยุบเป็นปุ่มขีดสามขีดที่มุมบนซ้าย

สองหัวข้อท้ายบทไม่มีเมนูของตัวเอง เพราะเป็นผลลัพธ์ของสิ่งที่ตั้งไว้ในหัวข้อก่อนหน้า

- **4.7 รายงานที่ส่งเข้า LINE** — ผลลัพธ์ของค่าที่ตั้งไว้ในหัวข้อ 4.6
- **4.8 ไฟล์ CSV ที่ส่งออกได้** — คอลัมน์ในแต่ละไฟล์ รูปแบบวันที่ และอายุของ
  ลิงก์ไฟล์หลักฐาน

## 4.1 ภาพรวม

หน้าแรกที่เห็นหลังเข้าสู่ระบบ หัวข้อหน้าคือ **"ภาพรวมระบบ"** คำโปรยว่า
*"วิเคราะห์การใช้งานและเฝ้าระวังความเสี่ยง"*

![ภาพที่ 4.1-1 หน้าภาพรวม ส่วนบน](images/04-01-dashboard-top.png)

*ภาพที่ 4.1-1 หน้าภาพรวม ส่วนบน — แคปให้เห็นตัวเลือกช่วงเวลาและแถวตัวเลข KPI ครบทั้งหกช่อง*

### ปุ่มบนหัวข้อหน้า

| ปุ่ม | ผลลัพธ์ |
|---|---|
| **พิมพ์รายงาน** | เมนูสองตัวเลือก: **พิมพ์ (แนวนอน)** และ **พิมพ์ (แนวตั้ง)** |
| **ส่งออกข้อมูล** | เมนูสามตัวเลือก: **ส่งออกสรุปภาพรวม**, **ส่งออกคลังพาเลท (CSV)**, **ส่งออกประวัติรายการ (CSV)** |

> **หมายเหตุ** ถ้ากดพิมพ์แล้วไม่มีอะไรเกิดขึ้น ให้ดูว่าเบราว์เซอร์บล็อกป๊อปอัปอยู่หรือไม่
> ระบบจะขึ้นข้อความเตือนไว้ให้แล้ว

#### เลือกแนวกระดาษ

ปุ่ม **พิมพ์รายงาน** มีให้เลือกสองแนว และมีอยู่เหมือนกันทั้งสามหน้า (ภาพรวม
คลังพาเลท ประวัติรายการ)

| ตัวเลือก | เหมาะกับ |
|---|---|
| **พิมพ์ (แนวนอน)** | หน้าภาพรวม และตารางที่มีหลายคอลัมน์ — เป็นค่าเริ่มต้น |
| **พิมพ์ (แนวตั้ง)** | รายงานที่มีคอลัมน์ไม่มาก และต้องการให้ได้จำนวนแถวต่อแผ่นมากขึ้น |

สิ่งที่ระบบจัดหน้าให้อัตโนมัติเมื่อสั่งพิมพ์:

- **การ์ดไม่ถูกตัดกลางหน้า** กราฟหรือกล่องตัวเลขที่ตกขอบล่างจะถูกยกไปทั้งใบยังหน้าถัดไป
- **หัวตารางซ้ำทุกหน้า** ตารางที่ยาวข้ามหน้า หน้าที่ 2 เป็นต้นไปยังมีชื่อคอลัมน์กำกับ
- **แถวไม่ถูกตัดครึ่ง** ไม่มีแถวไหนที่ครึ่งบนอยู่หน้าหนึ่งครึ่งล่างอยู่อีกหน้า
- **กราฟกว้างพอดีกระดาษ** ความกว้างถูกปรับตามแนวที่เลือก ไม่ล้นขอบขวา
- **ตัวควบคุมไม่ติดไปด้วย** ปุ่ม แถบตัวกรอง ช่องติ๊กเลือก และแถบเลขหน้า ไม่ปรากฏบนกระดาษ
- **หัวรายงานบนกระดาษ** ทุกแผ่นแรกมีชื่อรายงาน วันเวลาที่ออก และบรรทัดบอกตัวกรองที่ใช้อยู่

> **เลขหน้า "หน้า 1/5" มาจากเบราว์เซอร์ ไม่ใช่จากระบบ**
> ในกล่องพิมพ์ของ Chrome/Edge ให้กาง **"การตั้งค่าเพิ่มเติม"** แล้วติ๊ก
> **"หัวกระดาษและท้ายกระดาษ"** (ปกติติ๊กไว้อยู่แล้ว) เบราว์เซอร์จะใส่เลขหน้า
> วันที่ และ URL ให้เอง — ระบบใส่เลขหน้าลงกระดาษเองไม่ได้ เพราะ Chrome ไม่รองรับ
> คำสั่ง CSS ที่ใช้ทำเรื่องนี้

### ตัวเลือกช่วงเวลา

เลือกได้สี่ช่วง: **7 วัน / 30 วัน / 90 วัน / 12 เดือน**

> **หมายเหตุ** ช่วงเวลานี้มีผลกับ **กราฟเท่านั้น** ตัวเลข KPI แถวบนสุดเป็นค่า
> **ณ ตอนนี้** เสมอ ระบบเขียนกำกับไว้ใต้ตัวเลือกช่วงเวลาอยู่แล้วว่า จำนวนพาเลททั้งหมด
> อัตราการใช้งาน และรายการเกินกำหนด เป็นค่า ณ ปัจจุบัน

### แถวตัวเลข KPI

| ตัวเลข | นับอะไร |
|---|---|
| **พาเลททั้งหมด** | เฉพาะที่ยังใช้งาน ไม่รวมที่ตัดออกจากระบบ |
| **อัตราการใช้งาน** | ถูกเบิกออก ÷ พาเลททั้งหมด |
| **พร้อมใช้งาน** | อยู่ในคลัง พร้อมให้เบิก |
| **ถูกเบิกออก** | อยู่กับแผนกปลายทาง |
| **เกินกำหนด** | ถูกเบิกออกนานเกินเกณฑ์ที่ตั้งไว้ |
| **ชำรุด** | รอซ่อม หรือรอตัดสินใจตัดออกจากระบบ |

ใต้แถวนี้มีบรรทัดบอกจำนวนพาเลทที่ถูกตัดออกจากระบบแยกไว้ต่างหาก พร้อมกำกับว่า
**ไม่นับรวมในตัวเลขด้านบนทั้งหมด**

### ห้าส่วนของกราฟ

แถบนำทางด้านข้างมีห้าส่วน กดเพื่อเลื่อนไปยังส่วนนั้นได้ทันที

| ส่วน | กราฟที่มี |
|---|---|
| **ภาพรวมพาเลท** | สถานะพาเลทโดยรวม (วงกลม), ความเคลื่อนไหว (ยอดเบิกออกและรับคืน), การใช้งานตามสถานที่ |
| **วงจรการใช้งาน** | ระยะเวลาที่อยู่นอกคลัง, อายุรายการเกินกำหนด, พาเลทที่ไม่มีความเคลื่อนไหว |
| **คุณภาพ** | เส้นทางของพาเลทที่ชำรุด, ระยะเวลาจัดการพาเลทชำรุด, พาเลทที่ชำรุดซ้ำบ่อย, แนวโน้มคุณภาพพาเลท |
| **พนักงาน** | การทำรายการของพนักงาน — ใครบันทึกรายการไปเท่าไร |
| **เวลาทำรายการ** | ความถี่ตามวันและเวลา (ตารางความร้อน) |

![ภาพที่ 4.1-2 การวิเคราะห์เชิงลึก](images/04-01-dashboard-deepdive.png)

*ภาพที่ 4.1-2 การวิเคราะห์เชิงลึก — แคปหลังกดเปิดแล้ว ให้เห็นกราฟอย่างน้อยสองรูป*

**ส่วนแรกเปิดอยู่เสมอ อีกสี่ส่วนซ่อนไว้** กดปุ่ม **"ดูการวิเคราะห์เชิงลึก"** เพื่อเปิด
และ **"ซ่อนการวิเคราะห์เชิงลึก"** เพื่อปิด ทำแบบนี้เพื่อให้หน้าเปิดมาเจอสิ่งที่ต้องจัดการ
วันนี้ก่อน ไม่ใช่กราฟทั้งหมดพร้อมกัน

> **หมายเหตุ** ทุกกราฟมีปุ่ม **"ดูเป็นตาราง"** อยู่ใต้กราฟ กดแล้วจะได้ตัวเลขจริงในรูป
> ตาราง คัดลอกไปใส่รายงานได้ และโปรแกรมอ่านหน้าจอก็อ่านตารางนี้ได้ ต่างจากกราฟ
> ถ้าช่วงเวลาที่เลือกไม่มีข้อมูล กราฟจะขึ้นว่า **"ไม่มีข้อมูลในช่วงเวลาที่เลือก"**
> พร้อมแนะนำให้ขยายช่วงเวลา

## 4.2 คลังพาเลท

หน้านี้คือทะเบียนพาเลททุกใบในระบบ หัวข้อหน้าคือ **"จัดการคลังพาเลท"**

![ภาพที่ 4.2-1 หน้าคลังพาเลท](images/04-02-inventory.png)

*ภาพที่ 4.2-1 หน้าคลังพาเลท — แคปให้เห็นแถบสถานะ ตัวกรอง และตารางอย่างน้อย 5 แถว*

### ปุ่มบนหัวข้อหน้า

| ปุ่ม | ผลลัพธ์ |
|---|---|
| **พิมพ์รายงาน** | เมนูสองตัวเลือก: **พิมพ์ (แนวนอน)** และ **พิมพ์ (แนวตั้ง)** ดูรายละเอียดที่หัวข้อ "เลือกแนวกระดาษ" ในหัวข้อ 4.1 |
| **ส่งออกข้อมูล** | ดาวน์โหลดไฟล์ CSV **เฉพาะแถวที่ผ่านตัวกรองอยู่ตอนนี้** |
| **พิมพ์ QR ทั้งหมด** | เปิดหน้าต่างพิมพ์ QR Code ของพาเลททุกใบ |
| **เพิ่มพาเลท** | เปิดฟอร์มเพิ่มพาเลทใหม่ |

> **ทั้งไฟล์ CSV และกระดาษที่พิมพ์ ยึดตามตัวกรองที่ตั้งไว้ตอนนั้น** ไม่ใช่แค่หน้าที่
> กำลังเปิดอยู่ — กรองเหลือ 137 แถวแล้วอยู่ที่หน้า 1 (ซึ่งแสดง 20 แถว) กดพิมพ์
> จะได้ครบทั้ง 137 แถว ถ้าต้องการทั้งคลัง ให้กด **"ล้างตัวกรอง"** ก่อน
>
> บนกระดาษจะมี **คอลัมน์รูปหลักฐานเพิ่มเข้ามาอีกหนึ่งคอลัมน์** ซึ่งไม่มีบนหน้าจอ
> โดยจะแสดงรูปแจ้งชำรุดล่าสุดของพาเลทใบนั้น (ใบที่ไม่เคยมีรายงานชำรุดจะเว้นว่าง)
> ต้องต่ออินเทอร์เน็ตอยู่ตอนสั่งพิมพ์ เพราะเบราว์เซอร์โหลดรูปมาวางบนกระดาษให้ตอนนั้น
> และต้องสั่งพิมพ์ผ่านปุ่มนี้ ไม่ใช่ Ctrl+P (Ctrl+P จะได้ทุกอย่างยกเว้นรูป)

### แถบสถานะและตัวกรอง

แถบสถานะด้านบนตารางเป็นปุ่มกรองแบบกดครั้งเดียว: **ทั้งหมดที่ยังใช้งาน / พร้อมใช้งาน /
ถูกเบิกออก / ชำรุด / เกินกำหนด** แต่ละปุ่มแสดงจำนวนกำกับไว้ ส่วนพาเลทที่ถูกตัดออกจาก
ระบบไม่อยู่ในแถบนี้ แต่มีบรรทัดแยกอยู่ใต้แถบว่า *ตัดออกจากระบบแล้ว N รายการ*
พร้อมปุ่ม **"ดูรายการ"**

ถัดลงมาเป็นตัวกรองละเอียด

| ตัวกรอง | ใช้ทำอะไร |
|---|---|
| ช่องค้นหา | ค้นด้วยรหัสพาเลท |
| กรองตามสถานที่ | เลือกสถานที่เดียว หรือ **ทุกสถานที่** |
| กรองตามสถานะ | เหมือนแถบสถานะด้านบน |
| วันที่เริ่ม / วันที่สิ้นสุด | กรองตามช่วงเวลา |
| **เฉพาะเกินกำหนด** | แสดงเฉพาะพาเลทที่เบิกออกนานเกินเกณฑ์ |

ใต้ตัวกรองจะขึ้นจำนวนผลลัพธ์ในรูปแบบ *พบ N รายการ* และมีปุ่ม **"ล้างตัวกรอง"**

### เพิ่มพาเลทใหม่

![ภาพที่ 4.2-2 ฟอร์มเพิ่มพาเลทใหม่](images/04-02-add-pallet.png)

*ภาพที่ 4.2-2 ฟอร์มเพิ่มพาเลทใหม่*

1. กด **"เพิ่มพาเลท"**
2. ช่อง **รหัสพาเลท** ระบบเติมเลขถัดไปให้อัตโนมัติ (เช่น มีถึง `P023` อยู่แล้ว
   จะเติม `P024` ให้) ระหว่างที่กำลังคำนวณ ช่องนี้จะกดไม่ได้ชั่วครู่ ช่องอื่นยังกรอกได้
   ตามปกติ — **แก้เป็นรหัสอื่นได้เสมอ** ระบบแค่เติมค่าตั้งต้นให้ ไม่ได้ล็อกไว้
3. ช่อง **จำนวน** ใส่ได้ 1–100 ใบ ใต้ช่องจะขึ้นบรรทัดบอกช่วงที่จะได้ เช่น
   *จะสร้าง P024 – P043 รวม 20 ใบ* บรรทัดนี้เปลี่ยนตามที่พิมพ์ทันที
   **ตรวจรหัสสุดท้ายในบรรทัดนี้ก่อนกดยืนยันเสมอ** เพราะเป็นเลขที่ต้องเอาไปเทียบกับ
   สติกเกอร์ QR ที่กำลังจะพิมพ์
4. เลือก **สถานที่เริ่มต้น**
5. กด **"สร้างพาเลท"**
6. ระบบขึ้น **"สร้างพาเลท 20 ใบ P024 – P043 เรียบร้อยแล้ว"** (ถ้าสร้างใบเดียวจะขึ้น
   **"สร้างพาเลท P024 เรียบร้อยแล้ว"**) พาเลททุกใบมีสถานะ **พร้อมใช้งาน**

#### กติกาของเลขรันอัตโนมัติ

| กรณี | ระบบทำอย่างไร |
|---|---|
| ยังไม่มีพาเลทสักใบ | เริ่มที่ `P001` |
| มีถึง `P023` | เลขถัดไปคือ `P024` |
| `P010` ถูกลบไปแล้ว | **ไม่นำกลับมาใช้ซ้ำ** เลขถัดไปยังเป็น `P024` |
| มีรหัสหลุดรูปแบบปนอยู่ เช่น `TEST` | ข้ามไป ไม่นำมาคิด |
| เลขเกิน `P999` | ได้ `P1000` (ยาวขึ้นหนึ่งหลัก แต่ไม่ชนกับใคร) |

> **ทำไมไม่นำรหัสที่ลบไปแล้วกลับมาใช้ซ้ำ** เพราะรหัสอยู่บนสติกเกอร์ QR ที่แปะบน
> พาเลทจริง ถ้าเอาเลขเก่ากลับมาใช้ ประวัติของพาเลทใบเก่ากับใบใหม่จะปนกันอยู่ใต้
> รหัสเดียวกันในทุกรายงาน และแยกย้อนหลังไม่ได้อีกเลย

**ถ้าพิมพ์รหัสที่ไม่มีตัวเลขท้าย** เช่น `TEST` หรือ `SPECIAL-01` ช่องจำนวนจะถูกล็อก
เป็น 1 พร้อมข้อความบอกว่า *รหัสนี้ไม่มีตัวเลขท้ายรหัส จึงไม่มีลำดับให้นับต่อ
เพิ่มได้ครั้งละ 1 ใบเท่านั้น* — สร้างได้ปกติ แต่ทีละใบ

**ถ้ารหัสซ้ำ** (เช่น แอดมินอีกคนเพิ่งสร้างรหัสนั้นไปในอีกแท็บหนึ่ง) ระบบจะ
**ไม่สร้างสักใบเลยทั้งชุด** แล้วขึ้นข้อความใต้ช่องรหัสว่ารหัสไหนที่ชน พร้อมปุ่ม
**"คำนวณเลขใหม่"** กดแล้วระบบดึงรายการล่าสุดมาคำนวณเลขที่ว่างให้ใหม่ ไม่ต้องปิดเปิด
กล่องใหม่ — ค่าที่กรอกไว้ในช่องอื่นยังอยู่ครบ

หลังสร้างเสร็จ ให้พิมพ์ QR Code ของพาเลทใบนั้นไปติดที่ตัวพาเลทจริง ดูวิธีในหัวข้อย่อย
"พิมพ์ QR Code" ด้านล่าง

### การกระทำกับพาเลททีละใบ

คลิกที่แถวใดก็ได้เพื่อเปิดหน้าต่าง **รายละเอียดพาเลท** ซึ่งแสดงสถานที่ปัจจุบัน
รายการล่าสุด และไทม์ไลน์ประวัติทั้งหมดของพาเลทใบนั้น พร้อมชื่อผู้ทำรายการและรูปหลักฐาน

![ภาพที่ 4.2-3 หน้าต่างรายละเอียดพาเลท](images/04-02-pallet-detail.png)

*ภาพที่ 4.2-3 หน้าต่างรายละเอียดพาเลท — แคปพาเลทที่มีประวัติหลายรายการ*

ปุ่มท้ายแถวในตารางมีดังนี้ (บางปุ่มขึ้นเฉพาะบางสถานะ)

| ปุ่ม | ขึ้นเมื่อ | ผลลัพธ์ |
|---|---|---|
| **ทำเครื่องหมายว่าซ่อมแล้ว** | สถานะชำรุด | เปลี่ยนเป็น **พร้อมใช้งาน** และลบรูปหลักฐานความเสียหายทิ้ง |
| **ตัดออกจากระบบ** | สถานะชำรุด | เลิกใช้ถาวร แต่เก็บประวัติและรูปหลักฐานไว้ |
| **พิมพ์ QR Code** | ทุกสถานะ | เปิดหน้าต่างพิมพ์ QR ของใบนั้น |
| **แก้ไขข้อมูลพาเลท** | ทุกสถานะ | แก้รหัส สถานที่ และหมายเหตุ |
| **ลบพาเลท** | ทุกสถานะ | ลบทั้งพาเลทและประวัติทั้งหมด |

> **คำเตือน** **ลบ** กับ **ตัดออกจากระบบ** ไม่เหมือนกัน การลบทำให้ประวัติการทำรายการ
> ทั้งหมดของพาเลทใบนั้นหายไปด้วยและกู้คืนไม่ได้ ถ้าต้องการเลิกใช้พาเลทแต่ยังเก็บประวัติไว้
> ให้เลือก **ตัดออกจากระบบ** เสมอ ระบบเขียนคำเตือนนี้ไว้ในหน้าต่างยืนยันแล้ว ให้อ่านก่อนกด

> **ข้อควรระวัง** การแก้ไข **รหัสพาเลท** จะไปอัปเดตการอ้างอิงในประวัติทั้งหมดด้วย
> ระบบขึ้นคำเตือนไว้ในฟอร์มแก้ไขแล้ว

### ทำรายการกับพาเลทหลายใบพร้อมกัน

![ภาพที่ 4.2-4 แถบเครื่องมือเมื่อเลือกหลายรายการ](images/04-02-selection-bar.png)

*ภาพที่ 4.2-4 แถบเครื่องมือเมื่อเลือกหลายรายการ — แคปตอนเลือกไว้ 3 รายการขึ้นไป*

1. ติ๊กช่องหน้าแถวที่ต้องการ หรือติ๊กช่องบนหัวตารางเพื่อเลือกทั้งหน้า
2. แถบเครื่องมือจะโผล่ขึ้นมาพร้อมข้อความ *เลือกไว้ N รายการ* และปุ่มเหล่านี้

| ปุ่มในแถบ | ผลลัพธ์ |
|---|---|
| **ทำรายการ** | เปิดหน้าต่างสร้างรายการเบิกออกหรือรับคืนให้ทุกใบที่เลือก |
| **พิมพ์ QR** | พิมพ์ QR ของทุกใบที่เลือก |
| **แสดงรหัส / ซ่อนรหัส** | กางรายชื่อรหัสพาเลทที่เลือกไว้ให้ตรวจก่อนลงมือ |
| **ซ่อมแล้ว** | เปลี่ยนทุกใบที่เลือกเป็นพร้อมใช้งาน |
| **ตัดออกจากระบบ** | ตัดทุกใบที่เลือกออกจากระบบ |
| **ลบ** | ลบทุกใบที่เลือกพร้อมประวัติ |

> **หมายเหตุ** ปุ่ม **ซ่อมแล้ว** และ **ตัดออกจากระบบ** จะขึ้นก็ต่อเมื่อพาเลท
> **ทุกใบ** ที่เลือกไว้อยู่ในสถานะชำรุด ถ้าเลือกปนกับสถานะอื่น สองปุ่มนี้จะไม่ปรากฏ

**หน้าต่างสร้างรายการ**

![ภาพที่ 4.2-5 หน้าต่างสร้างรายการ](images/04-02-bulk-transaction.png)

*ภาพที่ 4.2-5 หน้าต่างสร้างรายการ — แคปตอนเลือกประเภทรายการเป็น "เบิกออก"*

3. เลือก **ประเภทรายการ**: **เบิกออก** หรือ **รับคืน**
4. ถ้าเลือกเบิกออก ต้องเลือก **ปลายทาง** ด้วย
5. แก้ **วันที่** และ **เวลา** ได้ ใช้เมื่อบันทึกย้อนหลังให้รายการที่เกิดไปแล้ว
6. ใส่ **หมายเหตุเพิ่มเติม (ถ้ามี)**
7. กด **"ยืนยัน"** ระบบขึ้น *ทำรายการสำเร็จ N รายการ*

ถ้าบางใบทำไม่สำเร็จ ระบบจะบอกทั้งจำนวนที่สำเร็จและรหัสที่ไม่สำเร็จ ไม่ใช่ล้มทั้งชุดเงียบ ๆ

### พิมพ์ QR Code

![ภาพที่ 4.2-6 หน้าต่างพิมพ์ QR Code](images/04-02-qr-print.png)

*ภาพที่ 4.2-6 หน้าต่างพิมพ์ QR Code — แคปตอนมี QR หลายใบเรียงในแผ่นเดียว*

หน้าต่าง **"แผ่นรวม QR พาเลท"** บอกจำนวนที่เลือกไว้ และมีสองปุ่ม

- **พิมพ์ / PDF** — เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ เลือก "บันทึกเป็น PDF" ได้จากตรงนั้น
- **ดาวน์โหลด PNG** — บันทึกแผ่น QR เป็นไฟล์รูป

QR แต่ละใบมีรหัสพาเลทกำกับใต้ภาพ พร้อมข้อความ **ทรัพย์สินของ NMT** แสดงความเป็นเจ้าของ

## 4.3 ประวัติรายการ

หน้านี้เก็บทุกรายการที่เคยเกิดในระบบ ไม่ว่าใครทำ หัวข้อหน้าคือ **"จัดการประวัติรายการ"**

![ภาพที่ 4.3-1 หน้าประวัติรายการ](images/04-03-transactions.png)

*ภาพที่ 4.3-1 หน้าประวัติรายการ — แคปให้เห็นรายการหลายประเภทและแถวที่มีรูปหลักฐาน*

### ตัวกรอง

| ตัวกรอง | ใช้ทำอะไร |
|---|---|
| ช่องค้นหา | ค้นด้วยรหัสพาเลท หรือข้อความในหมายเหตุ |
| กรองตามผู้ใช้ | เลือกดูเฉพาะรายการของคนใดคนหนึ่ง |
| กรองตามสถานที่ | เลือกสถานที่เดียว |
| กรองตามประเภทรายการ | เบิกออก / รับคืน / แจ้งชำรุด / ซ่อมแล้ว / ตัดออกจากระบบ |
| วันที่เริ่ม / ถึงวันที่ | กรองตามช่วงเวลา |

### ตาราง

คอลัมน์: **วันที่และเวลา / รหัสพาเลท / ประเภทรายการ / ผู้ทำรายการ / สถานที่ / หมายเหตุ / หลักฐาน**

- แถวที่มีรูปหลักฐาน จะมีปุ่ม **"ดูรูปหลักฐาน"** กดเพื่อเปิดรูปเต็ม
- ปุ่มท้ายแถวมี **"แก้ไขรายการ"** และ **"ลบรายการนี้"**

### แก้ไขรายการย้อนหลัง

![ภาพที่ 4.3-2 หน้าต่างแก้ไขรายการ](images/04-03-edit-transaction.png)

*ภาพที่ 4.3-2 หน้าต่างแก้ไขรายการ*

1. กดปุ่มแก้ไขท้ายแถวที่ต้องการ
2. **วันที่ (แก้ไขไม่ได้)** — ช่องนี้แสดงไว้ให้ดูเฉย ๆ แก้ไม่ได้
3. แก้ **สถานที่/ปลายทาง** และ **หมายเหตุ** ได้
4. กด **"บันทึกการแก้ไข"**

> **หมายเหตุ** ระบบจะต่อท้ายหมายเหตุด้วยข้อความ *(แก้ไข: วันที่, เวลา โดย ชื่อผู้แก้)*
> โดยอัตโนมัติ เพื่อให้รู้ว่ารายการนี้ถูกแก้ภายหลัง

> **ข้อควรระวัง** การแก้ไข **รายการล่าสุด** ของพาเลทใบหนึ่ง จะทำให้ระบบอัปเดต
> สถานที่ปัจจุบันของพาเลทใบนั้นตามไปด้วย ระบบเขียนหมายเหตุนี้ไว้ในหน้าต่างแก้ไขแล้ว

### พิมพ์ ส่งออก และล้างข้อมูลเก่า

- **พิมพ์รายงาน** — เมนูสองตัวเลือก **พิมพ์ (แนวนอน)** / **พิมพ์ (แนวตั้ง)**
  เหมือนหน้าภาพรวมและหน้าคลังพาเลท ได้ทุกแถวที่ผ่านตัวกรอง ไม่ใช่แค่หน้าที่เปิดอยู่
- **ส่งออกข้อมูล** — ดาวน์โหลดรายการตามตัวกรองที่ตั้งไว้ ระบบบอกจำนวนที่ส่งออกเมื่อเสร็จ
- **ล้างข้อมูลเก่า** — ลบรายการที่เก่ากว่า 2 ปีออกจากฐานข้อมูล

> **คำเตือน** การล้างข้อมูลเก่าลบข้อมูลอย่างถาวรและย้อนกลับไม่ได้ ควรกด
> **ส่งออกข้อมูล** เก็บไว้ก่อนทุกครั้ง

## 4.4 ผู้ใช้งาน

หัวข้อหน้าคือ **"จัดการผู้ใช้งาน"** ใช้จัดการบัญชีทั้งพนักงานและผู้ดูแลระบบ

![ภาพที่ 4.4-1 หน้าผู้ใช้งาน](images/04-04-users.png)

*ภาพที่ 4.4-1 หน้าผู้ใช้งาน — แคปให้เห็นทั้งบัญชีพนักงานและผู้ดูแลระบบ*

ตารางมีคอลัมน์ **รหัสพนักงาน / ชื่อ-นามสกุล / สถานที่ / บทบาท / วันที่สร้าง / เข้าใช้งานล่าสุด**
กรองได้ด้วยช่องค้นหา (ชื่อหรือรหัสพนักงาน) ตัวกรองสถานที่ และตัวกรองบทบาท
คลิกที่หัวคอลัมน์เพื่อเรียงลำดับได้

### เพิ่มผู้ใช้งานใหม่

![ภาพที่ 4.4-2 ฟอร์มเพิ่มผู้ใช้งานใหม่](images/04-04-create-user.png)

*ภาพที่ 4.4-2 ฟอร์มเพิ่มผู้ใช้งานใหม่ — แคปตอนกรอกรหัสผ่านครบสองช่องแล้วขึ้น "รหัสผ่านตรงกัน"*

1. กด **"เพิ่มผู้ใช้งาน"**
2. กรอก **รหัสพนักงาน** — ต้องไม่ซ้ำ เพราะระบบใช้ค่านี้สร้างอีเมลสำหรับเข้าสู่ระบบ
3. กรอก **ชื่อ-นามสกุล**
4. เลือก **แผนก**
5. เลือก **บทบาท**: พนักงาน หรือ ผู้ดูแลระบบ
6. กรอก **รหัสผ่าน** และ **ยืนยันรหัสผ่าน** ให้ตรงกัน
7. กด **"สร้างผู้ใช้งาน"**

> **หมายเหตุ** ถ้าสร้างบัญชีผู้ดูแลระบบแล้วขึ้นข้อความว่าสร้างสำเร็จแต่ยังเป็นสิทธิ์พนักงานอยู่
> แปลว่า **บัญชีถูกสร้างแล้วจริง** เพียงแต่ให้สิทธิ์ผู้ดูแลระบบไม่สำเร็จ อย่ากดสร้างซ้ำ
> ให้ไปเปลี่ยนบทบาทจากตารางแทน

### แก้ไข เปลี่ยนบทบาท และรีเซ็ตรหัสผ่าน

ปุ่มท้ายแถวมีสามปุ่ม

| ปุ่ม | ผลลัพธ์ |
|---|---|
| **แก้ไขผู้ใช้งาน** | เปลี่ยนแถวนั้นเป็นช่องกรอก แก้ **แผนก** และ **บทบาท** ได้ในแถวเลย แล้วกด **บันทึก** |
| **รีเซ็ตรหัสผ่าน** | เปิดหน้าต่างตั้งรหัสผ่านใหม่ให้ผู้ใช้คนนั้นโดยตรง |
| **ลบผู้ใช้งาน** | ลบบัญชีถาวร |

**วิธีรีเซ็ตรหัสผ่านให้พนักงานที่ลืมรหัส** — นี่คือวิธีที่เร็วที่สุด และเป็นวิธีที่ควรใช้
แทนการให้พนักงานกด "ลืมรหัสผ่าน?" เอง (ดูเหตุผลในหัวข้อ 2.2)

1. ค้นหาชื่อหรือรหัสพนักงานคนนั้น
2. กดปุ่ม **"รีเซ็ตรหัสผ่าน"** ท้ายแถว
3. หน้าต่างจะขึ้นว่า *กำลังรีเซ็ตรหัสผ่านของ ชื่อพนักงาน* — ตรวจว่าเป็นคนที่ถูกต้อง
4. กรอก **รหัสผ่านใหม่** และ **ยืนยันรหัสผ่านใหม่**
5. กด **"ยืนยันการรีเซ็ต"** แล้วแจ้งรหัสใหม่ให้พนักงานคนนั้นทราบ

> **คำเตือน** การลบผู้ใช้งานย้อนกลับไม่ได้ ระบบจะถามยืนยันพร้อมระบุชื่อและรหัสพนักงาน
> ให้อ่านชื่อในหน้าต่างยืนยันก่อนกดทุกครั้ง

## 4.5 สถานที่

หัวข้อหน้าคือ **"จัดการสถานที่"** รายการในหน้านี้คือสิ่งที่พนักงานเห็นตอนเลือกปลายทาง
ในหัวข้อ 3.2

![ภาพที่ 4.5-1 หน้าสถานที่](images/04-05-locations.png)

*ภาพที่ 4.5-1 หน้าสถานที่ — แคปให้เห็นทั้งสถานที่ที่เปิดและปิดใช้งาน*

ตารางมีคอลัมน์ **ลำดับ / ชื่อสถานที่ / รวม / เกินกำหนด / ชำรุด / อัปเดตล่าสุด / สถานะ / จัดการ**
ตัวเลขในคอลัมน์กลางบอกว่าสถานที่นั้นมีพาเลทอยู่กี่ใบ และมีปัญหากี่ใบ

ตัวกรองมีสองชุด: **ทุกสถานะ** (เปิด/ปิดใช้งาน) และ **ทุกเงื่อนไข** ซึ่งเลือกได้เป็น
**มีพาเลท / ไม่มีพาเลท / ⚠ มีพาเลทเกินกำหนด / ⚠ มีพาเลทชำรุด**

### เพิ่มสถานที่

1. กด **"เพิ่มสถานที่"**
2. กรอกชื่อ เช่น `คลังสินค้า A`
3. กด **"บันทึกสถานที่"**

> **หมายเหตุ** ชื่อสถานที่ห้ามซ้ำ และระบบเทียบชื่อโดย **ไม่สนตัวพิมพ์ใหญ่-เล็กและ
> ช่องว่างหน้าหลัง** ดังนั้น `Line A` กับ `line a` ถือเป็นสถานที่เดียวกัน

### เปิด/ปิดใช้งาน และลบ

| ปุ่ม | ผลลัพธ์ |
|---|---|
| **แก้ไขชื่อ** | เปลี่ยนแถวเป็นช่องกรอก แก้ชื่อแล้วกด **บันทึกการแก้ไข** |
| **ปิดใช้งาน** | สถานที่ยังอยู่ในระบบ แต่พนักงานจะไม่เห็นในหน้าเลือกปลายทางอีก |
| **เปิดใช้งาน** | กลับมาให้พนักงานเลือกได้ |
| **ลบสถานที่** | ลบถาวร |

> **หมายเหตุ** ลบสถานที่ที่ยังถูกใช้งานอยู่ไม่ได้ ระบบจะขึ้นว่า *ลบไม่ได้ เนื่องจาก
> สถานที่นี้ถูกใช้งานอยู่ กรุณาปิดใช้งานแทน* — ในกรณีนี้ให้ใช้ **ปิดใช้งาน**
> ซึ่งได้ผลเหมือนกันโดยไม่ทำให้ประวัติเสียหาย

หรือ **ตรวจสอบสถานะไม่ได้**

> **หมายเหตุ** ชื่อสองช่องนี้เป็นภาษาอังกฤษทั้งในโหมดภาษาไทย เพราะเป็นคำที่คอนโซล

> **หมายเหตุ** ค่าที่บันทึกแล้วจะถูกซ่อนไว้ ช่องจะแสดงเป็นจุดพร้อมข้อความ

### ส่วนที่ 3 โซนอันตราย

![ภาพที่ 4.6-3 โซนอันตราย](images/04-06-settings-danger.png)

*ภาพที่ 4.6-3 โซนอันตราย — สังเกตกรอบสีแดงและข้อความคำเตือน*

ส่วนล่างสุดที่มีกรอบสีแดง มีค่าเดียวคือ **อีเมลหลักของผู้ดูแลระบบ**
*(สำหรับเข้าสู่ระบบด้วยรหัสพนักงาน)*

ระบบสร้างอีเมลสำหรับเข้าสู่ระบบของผู้ใช้ทุกคนจากค่านี้ โดยแทรกรหัสพนักงานเข้าไป
เช่น อีเมลหลัก `admin@example.com` กับรหัสพนักงาน `EMP001` จะได้อีเมลเข้าสู่ระบบ
เป็น `admin+EMP001@example.com`

> **คำเตือน** การกด **"อัปเดตอีเมล"** จะเปลี่ยนอีเมลสำหรับเข้าสู่ระบบของ
> **ผู้ใช้ทุกคนพร้อมกันในครั้งเดียว** และย้อนกลับทีละคนไม่ได้ ผู้ใช้ทั้งหมดจะต้อง
> เข้าสู่ระบบด้วยโดเมนใหม่ ในการใช้งานปกติไม่มีเหตุผลให้ต้องแตะปุ่มนี้เลย
> แตะเฉพาะตอนย้ายอีเมลของระบบทั้งชุดเท่านั้น

## 4.7 รายงานที่ส่งเข้า LINE

หัวข้อนี้ไม่มีเมนูของตัวเอง เพราะมันคือ **ผลลัพธ์** ของสิ่งที่ตั้งไว้ในหัวข้อ 4.6
ระบบจะสรุปสถานะคลังส่งเข้า LINE ให้เองวันละสองรอบ โดยไม่ต้องมีใครเปิดหน้าจอ

รายงานส่งมาในรูปแบบ **Flex Message** ของ LINE ซึ่งเป็นการ์ดที่จัดวางเป็นส่วน ๆ
ไม่ใช่ข้อความตัวหนังสือธรรมดา จึงอ่านตัวเลขได้จากหน้าจอแจ้งเตือนเลยโดยไม่ต้องเปิดแอป

### รายงานสองรอบ ต่างกันอย่างไร

| | รอบเช้า | รอบเย็น |
|---|---|---|
| ชื่อบนการ์ด | **⚠️ OVERDUE ALERT** | **📊 DAILY SUMMARY** |
| สีหัวการ์ด | แดง | น้ำเงิน |
| ตอบคำถามว่า | มีพาเลทค้างอยู่ที่ไหนบ้าง ต้องตามคืน | วันนี้คลังมีอะไรอยู่เท่าไร |
| เวลาที่ส่ง | ตามช่อง **เวลาส่งแจ้งเตือน** (ค่าเริ่มต้น 08:00 น.) | ตามช่อง **เวลาส่งสรุปประจำวัน** (ค่าเริ่มต้น 16:00 น.) |
| ส่งเมื่อไร | **เฉพาะเมื่อมีพาเลทเกินกำหนด** | ส่งทุกครั้งที่ถึงเวลา |

> **หมายเหตุ** ข้อสุดท้ายในตารางสำคัญที่สุด **ถ้าวันนั้นไม่มีพาเลทเกินกำหนดเลย
> ระบบจะไม่ส่งรายงานรอบเช้าเลย** ไม่ใช่ส่งการ์ดเปล่ามาบอกว่าไม่มี การไม่ได้รับ
> ข้อความตอนเช้าจึงแปลว่า "ทุกอย่างปกติ" ไม่ใช่ "ระบบพัง" ส่วนรอบเย็นส่งทุกครั้ง
> ต่อให้ไม่มีความเคลื่อนไหวเลยก็ตาม

### หน้าตาการ์ดรอบเช้า — OVERDUE ALERT

![ภาพที่ 4.7-1 การ์ดแจ้งเตือนพาเลทเกินกำหนดใน LINE](images/04-07-line-overdue.png)

*ภาพที่ 4.7-1 การ์ดแจ้งเตือนพาเลทเกินกำหนดใน LINE — แคปจากหน้าจอแชท LINE ตอนมีพาเลทเกินกำหนดหลายสถานที่*

การ์ดแบ่งเป็นสามส่วนจากบนลงล่าง

| ส่วน | สิ่งที่แสดง | อ่านอย่างไร |
|---|---|---|
| หัวการ์ด (แดง) | `⚠️ OVERDUE ALERT` และบรรทัด `Daily Report: วันที่ (Overdue > N Days)` | เลข `N` คือเกณฑ์เกินกำหนดที่ตั้งไว้ในหัวข้อ 4.6 ไม่ใช่ค่าตายตัว |
| บรรทัดสรุป | `Found N overdue pallets.` | จำนวนพาเลทที่ค้างเกินเกณฑ์ทั้งหมด |
| รายการตามสถานที่ | ชื่อสถานที่ คู่กับจำนวน เช่น `Line A` … `3 pcs` | บอกว่าต้องไปตามที่แผนกไหนก่อน |
| บรรทัดปิดท้าย | `Please follow up immediately.` | ข้อความคงที่ ไม่ได้เปลี่ยนตามข้อมูล |

ระบบนับเฉพาะพาเลทที่อยู่ในสถานะ **ถูกเบิกออก** และเบิกออกไปนานเกินเกณฑ์เท่านั้น
พาเลทชำรุดหรือที่ตัดออกจากระบบแล้วไม่ถูกนับในรายงานนี้

### หน้าตาการ์ดรอบเย็น — DAILY SUMMARY

![ภาพที่ 4.7-2 การ์ดสรุปประจำวันใน LINE](images/04-07-line-summary.png)

*ภาพที่ 4.7-2 การ์ดสรุปประจำวันใน LINE — แคปจากหน้าจอแชท LINE ตอนมีพาเลทถูกเบิกออกอยู่หลายสถานที่*

การ์ดนี้ยาวกว่า แบ่งเป็นสี่ส่วน

| ส่วน | สิ่งที่แสดง | อ่านอย่างไร |
|---|---|---|
| หัวการ์ด (น้ำเงิน) | `📊 DAILY SUMMARY` และ `Daily Report: วันที่` | — |
| ตัวเลขใหญ่กลางการ์ด | `TOTAL PALLETS` พร้อมจำนวนรวม | จำนวนพาเลทที่ยังใช้งานอยู่ **ไม่รวมที่ตัดออกจากระบบ** ตรงกับตัวเลข "พาเลททั้งหมด" บนหน้าภาพรวม |
| สามช่องเรียงกัน | `Available` (เขียว) · `Damaged` (แดง) · `In Use` (เหลือง) | สามค่านี้บวกกันได้เท่ากับ `TOTAL PALLETS` พอดี |
| บรรทัดสีเทา | `Scrapped (excluded): N` | ขึ้นเฉพาะเมื่อมีพาเลทที่ถูกตัดออกจากระบบ และย้ำว่าไม่ถูกนับรวมข้างบน |
| `Active Locations (In Use)` | รายชื่อสถานที่ คู่กับจำนวนพาเลทที่ค้างอยู่ | ถ้าไม่มีพาเลทถูกเบิกออกเลย จะขึ้นว่า `No items currently in use.` |

> **หมายเหตุ** ข้อความบนการ์ดทั้งสองแบบเป็น **ภาษาอังกฤษเสมอ** ไม่เปลี่ยนตามปุ่ม
> สลับภาษาในแอป เพราะรายงานถูกสร้างจากฝั่งเซิร์ฟเวอร์ซึ่งไม่รู้ว่าคนอ่านตั้งภาษาอะไรไว้

### เงื่อนไขการส่ง

ระบบจะส่งรายงานก็ต่อเมื่อเข้าเงื่อนไขครบทุกข้อ

1. **วันนี้เป็นวันที่เลือกไว้** ในช่อง "วันส่งรายงานอัตโนมัติ"
2. **ถึงชั่วโมงที่ตั้งไว้** ระบบเทียบเฉพาะ **ชั่วโมง** ไม่ได้เทียบนาที ตั้งไว้ `08:30`
   กับ `08:00` จึงให้ผลเหมือนกัน คือส่งภายในชั่วโมงที่ 8
3. **ยังไม่ได้ส่งรอบนั้นของวันนี้ไป** ระบบจำไว้ว่าส่งรอบเช้าและรอบเย็นของวันไหนไปแล้ว
   ต่อให้ระบบถูกเรียกให้ทำงานหลายครั้งในชั่วโมงเดียวกัน รายงานก็ออกรอบละครั้งต่อวัน
4. **กรอกค่า LINE ครบแล้ว** ทั้ง Channel Access Token และ Your user ID

เวลาทั้งหมดอิงเขตเวลาประเทศไทย (UTC+7)

> **ข้อควรระวัง** ปุ่ม **"ทดสอบ"** ในหน้าตั้งค่าข้ามเงื่อนไขทั้งสี่ข้อนี้ทั้งหมด
> ส่งได้ทันทีไม่ว่าจะเป็นวันหรือเวลาใด และ **ไม่ถูกนับเป็นรอบของวันนั้น** ด้วย
> ทดสอบส่งตอน 9 โมงเช้า จึงไม่ทำให้รายงานจริงตอน 16:00 น. หายไป

> **ข้อควรระวัง** วันที่ที่พิมพ์อยู่บนหัวการ์ดคำนวณจากเวลามาตรฐานสากล ไม่ใช่เวลาไทย
> ถ้าตั้งเวลาส่งไว้ **ก่อน 07:00 น.** วันที่บนการ์ดจะเป็นของเมื่อวาน ในการใช้งานปกติ
> ที่ส่ง 08:00 น. และ 16:00 น. ไม่มีปัญหานี้

### ถ้าไม่ได้รับรายงาน ให้ไล่ตรวจตามนี้

| ตรวจข้อไหน | วิธีตรวจ |
|---|---|
| ค่า LINE ถูกต้องไหม | ดูป้ายสถานะในหัวข้อ 4.6 ว่าขึ้น **"ตั้งค่าแล้ว"** หรือยัง |
| ส่งได้จริงไหม | กด **"ทดสอบ"** → **"ส่งแจ้งเตือน"** ถ้าข้อความเข้า แปลว่าปลายทางถูกต้อง |
| เป็นเพราะไม่มีของค้างหรือเปล่า | รอบเช้าจะเงียบเมื่อไม่มีพาเลทเกินกำหนด ลองกดทดสอบส่ง **"ส่งสรุป"** แทน ถ้าเข้าแสดงว่าระบบปกติ |
| วันและเวลาตั้งไว้ถูกไหม | ตรวจว่าวันนี้ถูกเลือกไว้ และเวลาที่ตั้งผ่านไปแล้วจริง |
| ตั้งงานตามเวลาไว้หรือยัง | ปุ่มทดสอบทำงานได้ไม่ได้แปลว่ารายงานอัตโนมัติทำงาน สองอย่างนี้คนละทางกัน ดูภาคผนวก ก.5 ขั้นที่ 3 |

## 4.8 ไฟล์ CSV ที่ส่งออกได้

ระบบส่งออกได้สามไฟล์ **ทุกไฟล์ใช้รูปแบบวันที่และเวลาชุดเดียวกัน** คือ `dd/mm/yyyy`
กับ `HH:mm` แยกคนละคอลัมน์ จึงเอาไปเทียบหรือ VLOOKUP ข้ามไฟล์กันได้ทันที
ไม่ต้องแปลงรูปแบบก่อน

| ไฟล์ | กดได้จากที่ไหน | ได้อะไร |
|---|---|---|
| **คลังพาเลท** | ปุ่ม **"ส่งออกข้อมูล"** ในหน้าคลังพาเลท | เฉพาะแถวที่ผ่านตัวกรองตอนนั้น |
| | เมนู **ส่งออกข้อมูล → ส่งออกคลังพาเลท (CSV)** ในหน้าภาพรวม | ทั้งคลัง |
| **ประวัติรายการ** | ปุ่ม **"ส่งออกข้อมูล"** ในหน้าประวัติรายการ | เฉพาะแถวที่ผ่านตัวกรองตอนนั้น |
| | เมนู **ส่งออกข้อมูล → ส่งออกประวัติรายการ (CSV)** ในหน้าภาพรวม | ประวัติทั้งหมด |
| **สรุปภาพรวม** | เมนู **ส่งออกข้อมูล → ส่งออกสรุปภาพรวม** ในหน้าภาพรวม | ตัวเลขทุกกราฟบนหน้าภาพรวม |

ชื่อไฟล์: `nmt_current_inventory_DD-MM-YYYY.csv` และ
`nmt_transaction_history_DD-MM-YYYY.csv`

### ไฟล์ประวัติรายการ — 8 คอลัมน์

| # | คอลัมน์ | ตัวอย่าง |
|---|---|---|
| 1 | วันที่ | `22/07/2026` |
| 2 | เวลา | `09:05` |
| 3 | รหัสพาเลท | `P024` |
| 4 | ประเภทรายการ | `เบิกออก` |
| 5 | ผู้ทำรายการ | `สมชาย ใจดี` |
| 6 | สถานที่/ปลายทาง | `ฝ่ายผลิต` |
| 7 | หมายเหตุ | `ล้อแตกหนึ่งข้าง` |
| 8 | ลิงก์ไฟล์หลักฐาน | `https://...` |

**วันที่กับเวลาแยกคนละคอลัมน์** ทั้งสองไฟล์ เพื่อให้เรียงลำดับและกรองใน Excel ได้จริง
— ถ้ารวมอยู่ช่องเดียว Excel จะอ่านทั้งก้อนเป็นข้อความ แล้วเรียงตามตัวอักษรแทนที่จะ
เรียงตามเวลา

**รูปแบบวันที่เป็น `dd/mm/yyyy` ไม่ใช่ `21-Jul-2026` แบบที่เห็นบนหน้าจอ** เพราะ Excel
อ่าน `dd/mm/yyyy` เป็นวันที่จริง คอลัมน์จึงเรียง กรองตามเดือน และลบกันหาจำนวนวันได้
ส่วน `21-Jul-2026` Excel อ่านเป็นข้อความ เรียงแล้วจะได้ `Apr` มาก่อน `Jan`

**ช่องที่ไม่มีข้อมูล จะเว้นว่างไว้** เช่น พาเลทที่ยังไม่เคยถูกเบิกออกเลย ช่องวันที่และ
เวลาเบิกออกล่าสุดจะว่าง ไม่ใช่ขีด `-` แบบที่เห็นบนหน้าจอ — เพราะเซลล์ว่างคือสิ่งที่
Excel นับเป็น "ไม่มีค่า" ตัวกรองจึงมีตัวเลือก **(ว่าง)** ให้เลือกได้ และสูตรอย่าง
AVERAGE จะข้ามให้เอง ส่วนขีด `-` เป็นข้อความ ซึ่งจะถูกนับรวมเป็นค่าหนึ่ง

### ลิงก์ไฟล์หลักฐาน — อายุ 7 วัน

คอลัมน์สุดท้ายของ**ทั้งสองไฟล์**เป็น **ลิงก์เปิดรูปได้จริง** ไม่ใช่ชื่อไฟล์ กดจากใน
Excel แล้วรูปแจ้งชำรุดจะเปิดในเบราว์เซอร์

> ก่อนหน้านี้คอลัมน์นี้เก็บเป็นชื่อไฟล์ เช่น `P009_1785334256829.jpg` ซึ่งเปิดอะไร
> ไม่ได้เลย เพราะที่เก็บรูปของระบบไม่เปิดให้เข้าถึงสาธารณะ ต้องมีลิงก์ที่เซ็นแล้ว
> เท่านั้น

> **ลิงก์หมดอายุใน 7 วันนับจากวันที่ส่งออก** หลังจากนั้นจะเปิดไม่ได้อีก ถ้าต้องการ
> ไฟล์ที่ลิงก์ยังใช้ได้ ให้กดส่งออกใหม่ — ระบบเซ็นลิงก์ชุดใหม่ให้ทุกครั้ง
>
> เป็นเรื่องปกติของระบบที่เก็บรูปไว้แบบไม่เปิดสาธารณะ: ถ้าลิงก์ไม่มีวันหมดอายุ
> ไฟล์ CSV ที่ถูกส่งต่อออกไปจะกลายเป็นช่องทางเข้าถึงรูปในระบบแบบถาวร

### ภาษาไทยใน Excel

ไฟล์ที่ส่งออกทุกไฟล์เขียนสัญลักษณ์ UTF-8 กำกับไว้ที่ต้นไฟล์ ดับเบิลคลิกเปิดใน Excel
บน Windows ได้ทันที ภาษาไทยอ่านออกครบ ไม่ต้องตั้งค่าอะไรเพิ่ม

> ถ้ายังเจอภาษาไทยเพี้ยน แปลว่าไฟล์นั้นไม่ได้มาจากปุ่มในระบบ (เช่น เป็นไฟล์เก่าที่
> เก็บไว้ก่อนหน้านี้) ให้กดส่งออกใหม่
