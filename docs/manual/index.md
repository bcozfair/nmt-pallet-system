## หมายเหตุสำหรับผู้แก้ไขคู่มือ

คำที่หมายถึงปุ่มหรือป้ายบนหน้าจอ ต้องลอกจากไฟล์ `locales/th.ts` และ
`locales/admin/*.ts` ตรงตัวอักษรต่ออักษร ห้ามแปลเองหรือบัญญัติศัพท์ใหม่
ถ้าคู่มือกับหน้าจอใช้คนละคำ ผู้อ่านจะหาปุ่มไม่เจอ

ไฟล์ `manual.html` คือคู่มือทั้งเล่มรวมเป็นหน้าเดียว สำหรับอ่านต่อเนื่องและสั่งพิมพ์เป็น PDF
เมื่อแก้เนื้อหาในไฟล์ `.md` ต้องแก้ใน `manual.html` ให้ตรงกันด้วย
